### 🎴 Question / Flashcard #01
**Question / ප්‍රශ්නය:**
Which basic logic gate produces an output of HIGH (1) ONLY when ALL of its inputs are HIGH (1)?
සියලුම ආදානයන් උසස් (1) වන විට පමණක් ප්‍රතිදානය උසස් (1) ලබා දෙන මූලික තර්ක ද්වාරය කුමක්ද?

- (A) OR Gate / OR ද්වාරය
- (B) AND Gate / AND ද්වාරය
- (C) NOT Gate / NOT ද්වාරය
- (D) XOR Gate / XOR ද්වාරය

**Correct Answer / නිවැරදි පිළිතුර:** **(B)**

**Explanation & Flashcard Back / විස්තරය:**
* **English:** An AND gate performs logical multiplication ($Y = A \cdot B$). Its output is 1 only when both input $A = 1$ AND input $B = 1$. If any input is 0, the output is 0.
* **සිංහල:** AND ද්වාරයක් මගින් තර්කානුකූල ගුණ කිරීම සිදු කරයි ($Y = A \cdot B$). මෙහි $A = 1$ සහ $B = 1$ වන විට පමණක් ප්‍රතිදානය 1 වේ. ඕනෑම එක් ආදානයක් 0 වූ විට ප්‍රතිදානය 0 වේ.

### 🎴 Question / Flashcard #02
**Question / ප්‍රශ්නය:**
What is the Boolean expression for an OR gate with inputs $A$ and $B$?
$A$ සහ $B$ ආදානයන් සහිත OR ද්වාරයක බූලියානු ප්‍රකාශනය කුමක්ද?

- (A) $Y = A \cdot B$
- (B) $Y = A + B$
- (C) $Y = \bar{A}$
- (D) $Y = \overline{A \cdot B}$

**Correct Answer / නිවැරදි පිළිතුර:** **(B)**

**Explanation & Flashcard Back / විස්තරය:**
* **English:** An OR gate performs logical addition ($Y = A + B$). The output is 1 if at least one input is 1.
* **සිංහල:** OR ද්වාරයකින් තර්කානුකූල එකතු කිරීම සිදු කරයි ($Y = A + B$). අවම වශයෙන් එක් ආදානයක් 1 වූ විට ප්‍රතිදානය 1 වේ.

### 🎴 Question / Flashcard #03
**Question / ප්‍රශ්නය:**
How many inputs and outputs does a standard NOT gate (Inverter) have?
සම්මත NOT ද්වාරයක (ආවර්තකය) අඩංගු ආදාන සහ ප්‍රතිදාන ගණන කොපමණද?

- (A) 2 Inputs, 1 Output / ආදාන 2 යි, ප්‍රතිදාන 1 යි
- (B) 1 Input, 2 Outputs / ආදාන 1 යි, ප්‍රතිදාන 2 යි
- (C) 1 Input, 1 Output / ආදාන 1 යි, ප්‍රතිදාන 1 යි
- (D) 2 Inputs, 2 Outputs / ආදාන 2 යි, ප්‍රතිදාන 2 යි

**Correct Answer / නිවැරදි පිළිතුර:** **(C)**

**Explanation & Flashcard Back / විස්තරය:**
* **English:** A NOT gate is a single-input, single-output logic gate that inverts the input signal ($0 \rightarrow 1$ and $1 \rightarrow 0$).
* **සිංහල:** NOT ද්වාරය යනු තනි ආදානයක් සහ තනි ප්‍රතිදානයක් සහිත ද්වාරයකි. එය ලබාදෙන ආදානය අනුපූරණය/ප්‍රතිලෝම කරයි ($0 \rightarrow 1$ සහ $1 \rightarrow 0$).

### 🎴 Question / Flashcard #04
**Question / ප්‍රශ්නය:**
What is the output of an OR gate when the inputs are $A = 0$ and $B = 0$?
$A = 0$ සහ $B = 0$ වන විට OR ද්වාරයක ප්‍රතිදානය කුමක්ද?

- (A) 1
- (B) 0
- (C) Undefined / අර්ථ දක්වා නැත
- (D) High Impedance / ඉහළ බාධකතාව

**Correct Answer / නිවැරදි පිළිතුර:** **(B)**

**Explanation & Flashcard Back / විස්තරය:**
* **English:** For an OR gate, $Y = A + B$. Thus, $0 + 0 = 0$. The output is 0 only when all inputs are 0.
* **සිංහල:** OR ද්වාරයක $Y = A + B$ වේ. එබැවින් $0 + 0 = 0$ වේ. සියලු ආදාන 0 වන විට පමණක් OR ද්වාරයක ප්‍රතිදානය 0 වේ.

**Question / ප්‍රශ්නය:**
If the input to a NOT gate is $A = 1$, what will be the output $Y$?
NOT ද්වාරයකට ලබා දෙන ආදානය $A = 1$ නම්, එහි ප්‍රතිදානය $Y$ කුමක් වේද?

- (A) 1
- (B) 0
- (C) -1

**Explanation & Flashcard Back / විස්තරය:**
* **English:** The NOT gate inverts the logic state: $\bar{1} = 0$.

### 🎴 Question / Flashcard #06
**Question / ප්‍රශ්නය:**
Which truth table row correctly describes a 2-input AND gate?
ආදාන 2 ක AND ද්වාරයක සත්‍යතා වගු පේළි නිවැරදිව නිරූපණය කරන්නේ කුමක්ද?

- (A) $A=0, B=0 \rightarrow Y=1$
- (B) $A=1, B=0 \rightarrow Y=1$
- (C) $A=0, B=1 \rightarrow Y=1$

### 🎴 Question / Flashcard #07
**Question / ප්‍රශ්නය:**
What is the logic symbol feature that distinguishes a NOT gate symbol from a buffer?
NOT ද්වාරයක සංකේතය බෆරයකින් (Buffer) වෙනස් කර හඳුනා ගැනීමට ඇති විශේෂ ලක්ෂණය කුමක්ද?

- (A) A small circle (bubble) at the output / ප්‍රතිදානයේ ඇති කුඩා කඩතොලු/බබල් රවුම

- (C) Curved output line / වක්‍ර වූ ප්‍රතිදාන රේඛාව
- (D) Two output pins / ප්‍රතිදාන අග්‍ර දෙකක් පැවතීම

**Explanation & Flashcard Back / විස්තරය:**
* **English:** In digital circuit diagrams, a small circle (inversion bubble) at the output of a gate represents the logical NOT (inversion) operation.
* **සිංහල:** ඩිජිටල් පරිපථ සටහන්වල ද්වාරයක ප්‍රතිදාන අග්‍රයේ ඇති කුඩා රවුම (Bubble) මගින් තර්කානුකූල අනුපූරණය (NOT/Inversion) නිරූපණය කරයි.

### 🎴 Question / Flashcard #08
**Question / ප්‍රශ්නය:**
For a 3-input AND gate with inputs $A, B, C$, what is the output when $A=1, B=1, C=0$?
$A, B, C$ ආදාන 3 ක AND ද්වාරයකට $A=1, B=1, C=0$ ලබා දුන් විට ප්‍රතිදානය කුමක්ද?

- (A) 1
- (B) 0
- (C) 3
- (D) Undefined / අර්ථ දක්වා නැත

**Correct Answer / නිවැරදි පිළිතුර:** **(B)**

**Explanation & Flashcard Back / විස්තරය:**
* **English:** $Y = A \cdot B \cdot C = 1 \cdot 1 \cdot 0 = 0$. Since input $C$ is 0, the output of the AND gate becomes 0.
* **සිංහල:** $Y = A \cdot B \cdot C = 1 \cdot 1 \cdot 0 = 0$ වේ. $C$ ආදානය 0 වන බැවින් AND ද්වාරයේ ප්‍රතිදානය 0 වේ.

### 🎴 Question / Flashcard #09
**Question / ප්‍රශ්නය:**
For a 3-input OR gate with inputs $A, B, C$, what is the output when $A=0, B=0, C=1$?
$A, B, C$ ආදාන 3 ක OR ද්වාරයකට $A=0, B=0, C=1$ ලබා දුන් විට ප්‍රතිදානය කුමක්ද?

- (A) 0
- (B) 1
- (C) 2
- (D) Null

**Correct Answer / නිවැරදි පිළිතුර:** **(B)**

**Explanation & Flashcard Back / විස්තරය:**
* **English:** $Y = A + B + C = 0 + 0 + 1 = 1$. Since at least one input is 1, the OR gate output is 1.
* **සිංහල:** $Y = A + B + C = 0 + 0 + 1 = 1$ වේ. අවම වශයෙන් එක් ආදානයක් 1 වන බැවින් OR ද්වාරයේ ප්‍රතිදානය 1 වේ.

### 🎴 Question / Flashcard #10
**Question / ප්‍රශ්නය:**
How many total possible input combinations exist in a truth table for a circuit with $n$ inputs?
$n$ ප්‍රමාණයේ ආදාන ගණනක් සහිත පරිපථයක සත්‍යතා වගුවක පැවතිය හැකි මුළු ආදාන සංයෝජන ගණන කොපමණද?

- (A) $2n$
- (B) $n^2$
- (C) $2^n$
- (D) $2^{n+1}$

**Correct Answer / නිවැරදි පිළිතුර:** **(C)**

**Explanation & Flashcard Back / විස්තරය:**
* **English:** Since binary variables have 2 states (0 and 1), $n$ input variables result in $2^n$ unique truth table rows ($n=2 \rightarrow 4$ rows, $n=3 \rightarrow 8$ rows).
* **සිංහල:** ද්විමය සංඛ්‍යාවල පැවතිය හැක්කේ අගයන් 2 ක් (0 සහ 1) බැවින්, ආදාන $n$ ප්‍රමාණයක් සඳහා $2^n$ ප්‍රමාණයේ සංයෝජන පේළි ගණනක් සත්‍යතා වගුවේ පවතී.

### 🎴 Question / Flashcard #11
**Question / ප්‍රශ්නය:**
How many rows will a truth table have for a circuit with 3 inputs ($A, B, C$)?
ආදාන 3 ක් ($A, B, C$) සහිත පරිපථයක සත්‍යතා වගුවක පේළි ගණන කොපමණද?

- (A) 4
- (B) 6
- (C) 8
- (D) 16

**Correct Answer / නිවැරදි පිළිතුර:** **(C)**

### 2. Core Laws of Boolean Algebra

| Law Name (නියමයේ නම) | OR Form (OR ආකාරය) | AND Form (AND ආකාරය) |
| :--- | :--- | :--- |
| **Identity Law (අනන්‍යතා නියමය)** | $A + 0 = A$ | $A \cdot 1 = A$ |
| **Null / Annulment Law (ශූන්‍ය නියමය)** | $A + 1 = 1$ | $A \cdot 0 = 0$ |
| **Idempotent Law (ස්වයංසම නියමය)** | $A + A = A$ | $A \cdot A = A$ |
| **Complement Law (අනුපූරක නියමය)** | $A + \bar{A} = 1$ | $A \cdot \bar{A} = 0$ |
| **Double Negation (ද්විත්ව අනුපූරකය)** | $\overline{\bar{A}} = A$ | $\overline{\bar{A}} = A$ |
| **Commutative Law (පරිවර්ත්‍ය නියමය)** | $A + B = B + A$ | $A \cdot B = B \cdot A$ |
| **Associative Law (සංයෝජන නියමය)** | $A + (B + C) = (A + B) + C$ | $A \cdot (B \cdot C) = (A \cdot B) \cdot C$ |
| **Distributive Law (ව්‍යාප්ති නියමය)** | $A(B + C) = AB + AC$ | $A + BC = (A + B)(A + C)$ |
| **Absorption Law (අවශෝෂණ නියමය)** | $A + AB = A$ | $A(A + B) = A$ |
| **De Morgan's Laws (ඩි මොර්ගන්ගේ නියම)** | $\overline{A + B} = \bar{A} \cdot \bar{B}$ | $\overline{A \cdot B} = \bar{A} + \bar{B}$ |
