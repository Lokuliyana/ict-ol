# SECTION 1: Basic Logic Gates (මූලික තර්ක ද්වාර - AND, OR, NOT)

### Question 1 / ප්‍රශ්නය 1
**[English]:** Which basic logic gate produces an output of HIGH (1) ONLY when ALL of its inputs are HIGH (1)?
**[සිංහල]:** සියලුම ආදානයන් උසස් (1) වන විට පමණක් ප්‍රතිදානය උසස් (1) ලබා දෙන මූලික තර්ක ද්වාරය කුමක්ද?
- (A) OR Gate / OR ද්වාරය
- (B) AND Gate / AND ද්වාරය
- (C) NOT Gate / NOT ද්වාරය
- (D) XOR Gate / XOR ද්වාරය

**Answer / පිළිතුර:** **(B) AND Gate / AND ද්වාරය**
**Explanation / පැහැදිලි කිරීම:**
- **[English]:** An AND gate performs logical multiplication ($Y = A \cdot B$). Its output is 1 only when both input $A = 1$ AND input $B = 1$. If any input is 0, the output is 0.
- **[සිංහල]:** AND ද්වාරයක් මගින් තර්කානුකූල ගුණ කිරීම සිදු කරයි ($Y = A \cdot B$). මෙහි $A = 1$ සහ $B = 1$ වන විට පමණක් ප්‍රතිදානය 1 වේ. ඕනෑම එක් ආදානයක් 0 වූ විට ප්‍රතිදානය 0 වේ.

### Question 2 / ප්‍රශ්නය 2
**[English]:** What is the Boolean expression for an OR gate with inputs $A$ and $B$?
**[සිංහල]:** $A$ සහ $B$ ආදානයන් සහිත OR ද්වාරයක බූලියානු ප්‍රකාශනය කුමක්ද?
- (A) $Y = A \cdot B$
- (B) $Y = A + B$
- (C) $Y = \bar{A}$
- (D) $Y = \overline{A \cdot B}$

**Answer / පිළිතුර:** **(B) $Y = A + B$**
**Explanation / පැහැදිලි කිරීම:**
- **[English]:** An OR gate performs logical addition ($Y = A + B$). The output is 1 if at least one input is 1.
- **[සිංහල]:** OR ද්වාරයකින් තර්කානුකූල එකතු කිරීම සිදු කරයි ($Y = A + B$). අවම වශයෙන් එක් ආදානයක් 1 වූ විට ප්‍රතිදානය 1 වේ.

### Question 3 / ප්‍රශ්නය 3
**[English]:** How many inputs and outputs does a standard NOT gate (Inverter) have?
**[සිංහල]:** සම්මත NOT ද්වාරයක (ආවර්තකය) අඩංගු ආදාන සහ ප්‍රතිදාන ගණන කොපමණද?
- (A) 2 Inputs, 1 Output / ආදාන 2 යි, ප්‍රතිදාන 1 යි
- (B) 1 Input, 2 Outputs / ආදාන 1 යි, ප්‍රතිදාන 2 යි
- (C) 1 Input, 1 Output / ආදාන 1 යි, ප්‍රතිදාන 1 යි
- (D) 2 Inputs, 2 Outputs / ආදාන 2 යි, ප්‍රතිදාන 2 යි

**Answer / පිළිතුර:** **(C) 1 Input, 1 Output / ආදාන 1 යි, ප්‍රතිදාන 1 යි**
**Explanation / පැහැදිලි කිරීම:**
- **[English]:** A NOT gate is a single-input, single-output logic gate that inverts the input signal ($0 \rightarrow 1$ and $1 \rightarrow 0$).
- **[සිංහල]:** NOT ද්වාරය යනු තනි ආදානයක් සහ තනි ප්‍රතිදානයක් සහිත ද්වාරයකි. එය ලබාදෙන ආදානය අනුපූරණය/ප්‍රතිලෝම කරයි ($0 \rightarrow 1$ සහ $1 \rightarrow 0$).

### Question 4 / ප්‍රශ්නය 4
**[English]:** What is the output of an OR gate when the inputs are $A = 0$ and $B = 0$?
**[සිංහල]:** $A = 0$ සහ $B = 0$ වන විට OR ද්වාරයක ප්‍රතිදානය කුමක්ද?
- (A) 1
- (B) 0
- (C) Undefined / අර්ථ දක්වා නැත
- (D) High Impedance / ඉහළ බාධකතාව

**Answer / පිළිතුර:** **(B) 0**
**Explanation / පැහැදිලි කිරීම:**
- **[English]:** For an OR gate, $Y = A + B$. Thus, $0 + 0 = 0$. The output is 0 only when all inputs are 0.
- **[සිංහල]:** OR ද්වාරයක $Y = A + B$ වේ. එබැවින් $0 + 0 = 0$ වේ. සියලු ආදාන 0 වන විට පමණක් OR ද්වාරයක ප්‍රතිදානය 0 වේ.

### Question 5 / ප්‍රශ්නය 5
**[English]:** If the input to a NOT gate is $A = 1$, what will be the output $Y$?
**[සිංහල]:** NOT ද්වාරයකට ලබා දෙන ආදානය $A = 1$ නම්, එහි ප්‍රතිදානය $Y$ කුමක් වේද?
- (A) 1
- (B) 0
- (C) -1
- (D) 2

**Answer / පිළිතුර:** **(B) 0**
**Explanation / පැහැදිලි කිරීම:**
- **[English]:** The NOT gate inverts the logic state: $\bar{1} = 0$.
- **[සිංහල]:** NOT ද්වාරය මගින් තර්ක අගය ප්‍රතිලෝම කරයි: $\bar{1} = 0$.

### Question 6 / ප්‍රශ්නය 6
**[English]:** Which truth table row correctly describes a 2-input AND gate?
**[සිංහල]:** ආදාන 2 ක AND ද්වාරයක සත්‍යතා වගු පේළි නිවැරදිව නිරූපණය කරන්නේ කුමක්ද?
- (A) $A=0, B=0 \rightarrow Y=1$
- (B) $A=1, B=0 \rightarrow Y=1$
- (C) $A=0, B=1 \rightarrow Y=1$
- (D) $A=1, B=1 \rightarrow Y=1$

**Answer / පිළිතුර:** **(D) $A=1, B=1 \rightarrow Y=1$**
**Explanation / පැහැදිලි කිරීම:**
- **[English]:** An AND gate yields 1 only when both inputs are 1. For $(0,0 \rightarrow 0)$, $(0,1 \rightarrow 0)$, $(1,0 \rightarrow 0)$, and $(1,1 \rightarrow 1)$.
- **[සිංහල]:** AND ද්වාරයක ප්‍රතිදානය 1 වන්නේ ආදාන දෙකම 1 වූ විට පමණි.

### Question 7 / ප්‍රශ්නය 7
**[English]:** What is the logic symbol feature that distinguishes a NOT gate symbol from a buffer?
**[සිංහල]:** NOT ද්වාරයක සංකේතය බෆරයකින් (Buffer) වෙනස් කර හඳුනා ගැනීමට ඇති විශේෂ ලක්ෂණය කුමක්ද?
- (A) A small circle (bubble) at the output / ප්‍රතිදානයේ ඇති කුඩා කඩතොලු/බබල් රවුම

- (C) Curved output line / වක්‍ර වූ ප්‍රතිදාන රේඛාව
- (D) Two output pins / ප්‍රතිදාන අග්‍ර දෙකක් පැවතීම

**Answer / පිළිතුර:** **(A) A small circle (bubble) at the output / ප්‍රතිදානයේ ඇති කුඩා කඩතොලු/බබල් රවුම**
**Explanation / පැහැදිලි කිරීම:**
- **[English]:** In digital circuit diagrams, a small circle (inversion bubble) at the output of a gate represents the logical NOT (inversion) operation.
- **[සිංහල]:** ඩිජිටල් පරිපථ සටහන්වල ද්වාරයක ප්‍රතිදාන අග්‍රයේ ඇති කුඩා රවුම (Bubble) මගින් තර්කානුකූල අනුපූරණය (NOT/Inversion) නිරූපණය කරයි.

### Question 8 / ප්‍රශ්නය 8
**[English]:** For a 3-input AND gate with inputs $A, B, C$, what is the output when $A=1, B=1, C=0$?
**[සිංහල]:** $A, B, C$ ආදාන 3 ක AND ද්වාරයකට $A=1, B=1, C=0$ ලබා දුන් විට ප්‍රතිදානය කුමක්ද?
- (A) 1
- (B) 0
- (C) 3
- (D) Undefined / අර්ථ දක්වා නැත

**Answer / පිළිතුර:** **(B) 0**
**Explanation / පැහැදිලි කිරීම:**
- **[English]:** $Y = A \cdot B \cdot C = 1 \cdot 1 \cdot 0 = 0$. Since input $C$ is 0, the output of the AND gate becomes 0.
- **[සිංහල]:** $Y = A \cdot B \cdot C = 1 \cdot 1 \cdot 0 = 0$ වේ. $C$ ආදානය 0 වන බැවින් AND ද්වාරයේ ප්‍රතිදානය 0 වේ.

### Question 9 / ප්‍රශ්නය 9
**[English]:** For a 3-input OR gate with inputs $A, B, C$, what is the output when $A=0, B=0, C=1$?
**[සිංහල]:** $A, B, C$ ආදාන 3 ක OR ද්වාරයකට $A=0, B=0, C=1$ ලබා දුන් විට ප්‍රතිදානය කුමක්ද?
- (A) 0
- (B) 1
- (C) 2
- (D) Null

**Answer / පිළිතුර:** **(B) 1**
**Explanation / පැහැදිලි කිරීම:**
- **[English]:** $Y = A + B + C = 0 + 0 + 1 = 1$. Since at least one input is 1, the OR gate output is 1.
- **[සිංහල]:** $Y = A + B + C = 0 + 0 + 1 = 1$ වේ. අවම වශයෙන් එක් ආදානයක් 1 වන බැවින් OR ද්වාරයේ ප්‍රතිදානය 1 වේ.

### Question 10 / ප්‍රශ්නය 10
**[English]:** How many total possible input combinations exist in a truth table for a circuit with $n$ inputs?
**[සිංහල]:** $n$ ප්‍රමාණයේ ආදාන ගණනක් සහිත පරිපථයක සත්‍යතා වගුවක පැවතිය හැකි මුළු ආදාන සංයෝජන ගණන කොපමණද?
- (A) $2n$
- (B) $n^2$
- (C) $2^n$
- (D) $2^{n+1}$

**Answer / පිළිතුර:** **(C) $2^n$**
**Explanation / පැහැදිලි කිරීම:**
- **[English]:** Since binary variables have 2 states (0 and 1), $n$ input variables result in $2^n$ unique truth table rows ($n=2 \rightarrow 4$ rows, $n=3 \rightarrow 8$ rows).
- **[සිංහල]:** ද්විමය සංඛ්‍යාවල පැවතිය හැක්කේ අගයන් 2 ක් (0 සහ 1) බැවින්, ආදාන $n$ ප්‍රමාණයක් සඳහා $2^n$ ප්‍රමාණයේ සංයෝජන පේළි ගණනක් සත්‍යතා වගුවේ පවතී.

### Question 11 / ප්‍රශ්නය 11
**[English]:** How many rows will a truth table have for a circuit with 3 inputs ($A, B, C$)?

# SECTION 2: Derived / Combinational Logic Gates (සංයුක්ත තර්ක ද්වාර - NAND, NOR, XOR, XNOR)

**[සිංහල]:** $A=0$ සහ $B=1$ වන විට ආදාන 2 ක XOR ද්වාරයක ප්‍රතිදානය කුමක්ද?
- (A) 0

- (D) Null

**Explanation / පැහැදිලි කිරීම:**
- **[English]:** Since $A \neq B$ ($0$ and $1$), the XOR gate produces an output of 1 ($0 \oplus 1 = 1$).
- **[සිංහල]:** $A$ සහ $B$ ආදානයන් වෙනස් නිසා ($0$ සහ $1$), XOR ද්වාරයේ ප්‍රතිදානය 1 වේ ($0 \oplus 1 = 1$).

### Question 24 / ප්‍රශ්නය 24

- (D) OR Gate / OR ද්වාරය

### Question 27 / ප්‍රශ්නය 27

**[සිංහල]:** ආදාන 2 ක NAND ද්වාරයක ආදාන දෙකම එකට එකතු කර $A$ තනි සංඥාවට සම්බන්ධ කළ විට ලැබෙන ප්‍රතිඵලය කුමක්ද?

# SECTION 3: Boolean Algebra & De Morgan's Laws (බූලියානු වීජ ගණිතය සහ ඩි මොර්ගන්ගේ නියම)

### Question 31 / ප්‍රශ්නය 31
**[English]:** What is De Morgan's First Law for the complement of a product: $\overline{A \cdot B}$?
**[සිංහල]:** ඩි මොර්ගන්ගේ පළමු නියමයට අනුව गुणनผลයක අනුපූරකය වන $\overline{A \cdot B}$ සඳහා සමාන වන්නේ කුමක්ද?
- (A) $\bar{A} \cdot \bar{B}$
- (B) $\bar{A} + \bar{B}$
- (C) $A + B$
- (D) $\overline{A + B}$

**Answer / පිළිතුර:** **(B) $\bar{A} + \bar{B}$**
**Explanation / පැහැදිලි කිරීම:**
- **[English]:** De Morgan's 1st Law states that the complement of a product is equal to the sum of the complements: $\overline{A \cdot B} = \bar{A} + \bar{B}$.
- **[සිංහල]:** ඩි මොර්ගන්ගේ 1 වන නියමයට අනුව, ගුණිතයක අනුපූරකය වෙන වෙනම අනුපූරකයන්ගේ එකතුවට සමාන වේ: $\overline{A \cdot B} = \bar{A} + \bar{B}$.

---

### Question 32 / ප්‍රශ්නය 32
**[English]:** What is De Morgan's Second Law for the complement of a sum: $\overline{A + B}$?
**[සිංහල]:** ඩි මොර්ගන්ගේ දෙවන නියමයට අනුව එකතුවක අනුපූරකය වන $\overline{A + B}$ සඳහා සමාන වන්නේ කුමක්ද?
- (A) $\bar{A} \cdot \bar{B}$
- (B) $\bar{A} + \bar{B}$
- (C) $A \cdot B$
- (D) $\overline{A \cdot B}$

**Answer / පිළිතුර:** **(A) $\bar{A} \cdot \bar{B}$**
**Explanation / පැහැදිලි කිරීම:**
- **[English]:** De Morgan's 2nd Law states that the complement of a sum is equal to the product of the complements: $\overline{A + B} = \bar{A} \cdot \bar{B}$.
- **[සිංහල]:** ඩි මොර්ගන්ගේ 2 වන නියමයට අනුව, එකතුවක අනුපූරකය වෙන වෙනම අනුපූරකයන්ගේ ගුණිතයට සමාන වේ: $\overline{A + B} = \bar{A} \cdot \bar{B}$.

### Question 33 / ප්‍රශ්නය 33
**[English]:** According to the Idempotent Law, what is $A + A$?
**[සිංහල]:** ස්වයංසම නියමයට (Idempotent Law) අනුව, $A + A$ හි අගය කුමක්ද?
- (A) $2A$
- (B) $A^2$
- (C) $A$
- (D) 1

**Answer / පිළිතුර:** **(C) $A$**
**Explanation / පැහැදිලි කිරීම:**

- (C) $A \cdot B \cdot C$

### Question 57 / ප්‍රශ්නය 57
**[English]:** What is the boolean function for a Half Adder's Sum ($S$) output with inputs $A$ and $B$?
**[සිංහල]:** $A$ සහ $B$ ආදාන සහිත අර්ධ එකතුකරණයක (Half Adder) එකතුව ($S$) සඳහා වන බූලියානු ශ්‍රිතය කුමක්ද?

- (B) $S = A \oplus B$
- (C) $S = A + B$
- (D) $S = \overline{A \cdot B}$

**Answer / පිළිතුර:** **(B) $S = A \oplus B$**
**Explanation / පැහැදිලි කිරීම:**
- **[English]:** In a Half Adder circuit, the Sum bit is computed using an XOR gate ($S = A \oplus B$), while the Carry bit is computed using an AND gate ($C = A \cdot B$).
- **[සිංහල]:** අර්ධ එකතුකරණ පරිපථයක එකතු කිරීමේ බිටුව ($S$) XOR ද්වාරයකින්ද ($S = A \oplus B$), ශේෂ බිටුව ($C$) AND ද්වාරයකින්ද ($C = A \cdot B$) ගණනය කරයි.

### Question 58 / ප්‍රශ්නය 58
**[English]:** What is the boolean function for a Half Adder's Carry ($C$) output with inputs $A$ and $B$?
**[සිංහල]:** $A$ සහ $B$ ආදාන සහිත අර්ධ එකතුකරණයක (Half Adder) ශේෂය ($C$) සඳහා වන බූලියානු ශ්‍රිතය කුමක්ද?
- (A) $C = A \cdot B$
- (B) $C = A \oplus B$
- (C) $C = A + B$
- (D) $C = \bar{A}B$

**Answer / පිළිතුර:** **(A) $C = A \cdot B$**
**Explanation / පැහැදිලි කිරීම:**
- **[English]:** Carry occurs only when both bits are 1 ($1+1 = 10_2 \rightarrow \text{Sum}=0, \text{Carry}=1$), modeled by an AND gate ($C = A \cdot B$).
- **[සිංහල]:** බිටු දෙකම 1 වන විට පමණක් ශේෂයක් ($C=1$) ජනනය වේ ($1+1 = 10_2$). එය AND ද්වාරයකින් ආකෘතිකරණය වේ ($C = A \cdot B$).

### Question 59 / ප්‍රශ්නය 59
**[English]:** Which logic circuit combination represents the expression $Y = \bar{A}\bar{B}$?
**[සිංහල]:** $Y = \bar{A}\bar{B}$ ප්‍රකාශනය නිරූපණය කරන පරිපථ සංයෝජනය කුමක්ද?
- (A) Inputs $A$ and $B$ passed through NOT gates, then into an AND gate / $A$ සහ $B$ ආදානයන් NOT ද්වාර හරහා යවා පසුව AND ද්වාරයකට දීම
- (B) Inputs $A$ and $B$ passed into a NOR gate / $A$ සහ $B$ ආදානයන් NOR ද්වාරයකට දීම
- (C) Both (A) and (B) according to De Morgan's Law / ඩි මොර්ගන්ගේ නියමයට අනුව (A) සහ (B) දෙකම
- (D) Neither (A) nor (B) / (A) හෝ (B) දෙකම නොවේ

**Answer / පිළිතුර:** **(C) Both (A) and (B) according to De Morgan's Law / ඩි මොර්ගන්ගේ නියමයට අනුව (A) සහ (B) දෙකම**
**Explanation / පැහැදිලි කිරීම:**
- **[English]:** By De Morgan's Law, $\overline{A + B} = \bar{A} \cdot \bar{B}$. A NOR gate is equivalent to an AND gate with inverted inputs (Active-Low AND).
- **[සිංහල]:** ඩි මොර්ගන්ගේ නියමයට අනුව $\overline{A + B} = \bar{A} \cdot \bar{B}$ වේ. එනම් NOR ද්වාරයක් යනු ආදානයන් ප්‍රතිලෝම කළ AND ද්වාරයකට සමාන වේ.

### Question 60 / ප්‍රශ්නය 60
**[English]:** What is the simplified expression for $Y = A\bar{B}C + A\bar{B}\bar{C}$?
**[සිංහල]:** $Y = A\bar{B}C + A\bar{B}\bar{C}$ සඳහා සරල කළ ප්‍රකාශනය කුමක්ද?
- (A) $A\bar{B}$
- (B) $AC$
- (C) $A + B$
- (D) $ABC$

**Answer / පිළිතුර:** **(A) $A\bar{B}$**
**Explanation / පැහැදිලි කිරීම:**
- **[English]:** Factor out $A\bar{B}$: $Y = A\bar{B}(C + \bar{C})$. Since $C + \bar{C} = 1$, $Y = A\bar{B}(1) = A\bar{B}$.
- **[සිංහල]:** $A\bar{B}$ පොදුවේ පිටතට ගත් විට: $Y = A\bar{B}(C + \bar{C})$ වේ. $C + \bar{C} = 1$ බැවින්, $Y = A\bar{B}(1) = A\bar{B}$ වේ.

### 2. Core Laws of Boolean Algebra

| Law Name (නියමයේ නම) | OR Form (OR ආකාරය) | AND Form (AND ආකාරය) |
| :--- | :--- | :--- |
| **Identity Law (අනන්‍යතා නියමය)** | $A + 0 = A$ | $A \cdot 1 = A$ |
| **Null / Annulment Law (ශූන්‍ය නියමය)** | $A + 1 = 1$ | $A \cdot 0 = 0$ |
| **Idempotent Law (ස්වයංසම නියමය)** | $A + A = A$ | $A \cdot A = A$ |
| **Complement Law (අනුපූරක නියමය)** | $A + \bar{A} = 1$ | $A \cdot \bar{A} = 0$ |
| **Double Negation (ද්විත්ව අනුපූරකය)** | $\overline{\bar{A}} = A$ | $\overline{\bar{A}} = A$ |
| **Commutative Law (පරිවර්ත්‍ය නියමය)** | $A + B = B + A$ | $A \cdot B = B \cdot A$ |
| **Associative Law (සංයෝජන නියමය)** | $A + (B + C) = (A + B) + C$ | $A \cdot (B \cdot C) = (A \cdot B) \cdot C$ |
| **Distributive Law (ව්‍යාප්ති නියමය)** | $A(B + C) = AB + AC$ | $A + BC = (A + B)(A + C)$ |
| **Absorption Law (අවශෝෂණ නියමය)** | $A + AB = A$ | $A(A + B) = A$ |
| **De Morgan's Laws (ඩි මොර්ගන්ගේ නියම)** | $\overline{A + B} = \bar{A} \cdot \bar{B}$ | $\overline{A \cdot B} = \bar{A} + \bar{B}$ |
