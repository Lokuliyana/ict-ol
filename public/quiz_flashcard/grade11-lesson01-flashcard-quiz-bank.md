#### Q01. What is an algorithm in problem solving? / ගැටලු විසඳීමේදී ඇල්ගොරිතමයක් (Algorithm) යනු කුමක්ද?
A. A computer program written in Pascal language / පැස්කල් භාෂාවෙන් ලියන ලද පරිගණක ක්‍රමලේඛයක්  
B. A step-by-step sequence of instructions to solve a given problem in finite steps / යම් ගැටලුවක් සීමිත පියවර ගණනකින් විසඳීම සඳහා ඇති පියවරෙන් පියවර උපදෙස් මාලාවක්  
C. A hardware device inside the CPU / CPU එක තුළ ඇති භෞතික දෘඩාංග උපාංගයක්  
D. An error that occurs during program compilation / ක්‍රමලේඛයක් සම්පාදනය කිරීමේදී සිදුවන දෝෂයක්

**Correct Answer:** **B. A step-by-step sequence of instructions to solve a given problem in finite steps / යම් ගැටලුවක් සීමිත පියවර ගණනකින් විසඳීම සඳහා ඇති පියවරෙන් පියවර උපදෙස් මාලාවක්**

- **English Explanation:** An algorithm is a well-defined, step-by-step logical sequence of finite instructions designed to perform a task or solve a specific problem. It must be unambiguous, clear, and terminate after a finite number of steps.
- **Sinhala Explanation:** ඇල්ගොරිතමයක් යනු යම් ගැටලුවක් නිරාකරණය කර ගැනීම සඳහා අනුගමනය කළ යුතු අනුක්‍රමික, පැහැදිලි සහ සීමිත පියවර මාලාවකි. එය කිසිවිටෙකත් අනන්තයට නොයා සීමිත පියවර ගණනකින් අවසන් විය යුතුය.

#### Q02. Which flowchart symbol is correctly matched with its function? / පහත දැක්වෙන ප්‍රවාහ සටහන් සංකේත අතුරින් එහි කාර්යය නිවැරදිව ගැලපෙන්නේ කුමක්ද?
A. Rectangle (සෘජුකෝණාස්‍රය) $ightarrow$ Decision making (තීරණ ගැනීම)  
B. Diamond / Rhombus (රොම්බසය) $ightarrow$ Processing operation (ක්‍රියාවලිය / ගණනය කිරීම්)  
C. Parallelogram (සමානතරාස්‍රය) $ightarrow$ Input / Output operations (ආදානය / ප්රතිදානය)  
D. Oval / Pill shape (ඕ Oval/ඉලිප්සය) $ightarrow$ Connector (සම්බන්ධකය)

#### Q03. What are the three fundamental control structures used in algorithms? / ඇල්ගොරිතමවල භාවිත වන මූලික පාලන ව්‍යුහයන් (Control Structures) තුන කුමක්ද?
A. Input, Process, Output / ආදානය, ක්‍රියාවලිය, ප්‍රතිදානය  
B. Sequence, Selection, Iteration (Repetition) / අනුක්‍රමය, තේරීම, පුනරාවර්තනය  
C. Compiler, Interpreter, Assembler / කම්පයිලරය, ඉන්ටප්‍රිටරය, ඇසෙම්බ්ලරය  
D. Integer, Real, Boolean / පූර්ණ සංඛ්‍යා, තාත්වික සංඛ්‍යා, බූලියානු  

<details>
<summary><b>View Answer & Flashcard Explanation (පිළිතුර සහ ෆ්ලෑෂ්කාඩ් විස්තරය බලන්න)</b></summary>

**Correct Answer:** **B. Sequence, Selection, Iteration (Repetition) / අනුක්‍රමය, තේරීම, පුනරාවර්තනය**

- **English Explanation:** All structured algorithms are constructed using three control structures:
  1. **Sequence:** Executing statements line-by-line in order.
  2. **Selection / Condition:** Choosing between alternative paths based on a condition (`if..then..else`).
  3. **Iteration / Loop:** Repeating a block of code multiple times (`for`, `while`, `repeat..until`).
- **Sinhala Explanation:** ඕනෑම පද්ධතිමය ඇල්ගොරිතමයක් සෑදී ඇත්තේ පාලන ව්‍යුහයන් 3 කිනි:
  1. **අනුක්‍රමය (Sequence):** පියවරෙන් පියවර අනුපිළිවෙලින් ක්‍රියාත්මක වීම.
  2. **තේරීම (Selection):** කොන්දේසියක් මත පදනම්ව මාවතක් තෝරා ගැනීම.
  3. **පුනරාවර්තනය (Iteration/Loop):** යම් කොන්දේසියක් සපිරෙන තෙක් කේත කොටසක් නැවත නැවත ක්‍රියාත්මක වීම.
</details>

#### Q04. Which pseudo code statement represents an Iteration (Loop) structure? / පහත pseudo code කේත අතුරින් පුනරාවර්තන ව්‍යුහයක් (Iteration Structure) නිරූපණය කරන්නේ කුමක්ද?
A. `IF Marks >= 50 THEN Print "Pass" ELSE Print "Fail"`  
B. `FOR count = 1 TO 10 DO Print count`  
C. `SET Sum = Num1 + Num2`  
D. `READ Student_Name`  

<details>
<summary><b>View Answer & Flashcard Explanation (පිළිතුර සහ ෆ්ලෑෂ්කාඩ් විස්තරය බලන්න)</b></summary>

**Correct Answer:** **B. FOR count = 1 TO 10 DO Print count**

- **English Explanation:** `FOR..TO..DO` is a definite loop structure used for **Iteration** (repeating a set of statements 10 times). Option A represents Selection (`IF..THEN`), while C and D represent Sequence/Processing/Input.
- **Sinhala Explanation:** `FOR..TO..DO` යනු පුනරාවර්තන (Loop) ව්‍යුහයකි. එය 1 සිට 10 දක්වා 10 වතාවක් නියමිත ක්‍රියාව නැවත සිදු කරයි. A යනු තේරීමක් (Selection) වන අතර C සහ D යනු අනුක්‍රමික ක්‍රියා වේ.
</details>

#### Q05. What is the output of the following algorithm if the input value for `N` is 7? / `N` සඳහා ආදාන අගය 7 ලෙස ලබා දුනහොත් පහත ඇල්ගොරිතමයේ ප්‍රතිදානය කුමක්ද?
```text
BEGIN
   READ N
   IF N MOD 2 = 0 THEN
      PRINT "EVEN"
   ELSE
      PRINT "ODD"
   ENDIF
END
```
A. EVEN  
B. ODD  
C. 7  
D. Error  

<details>
<summary><b>View Answer & Flashcard Explanation (පිළිතුර සහ ෆ්ලෑෂ්කාඩ් විස්තරය බලන්න)</b></summary>

**Correct Answer:** **B. ODD**

- **English Explanation:** `7 MOD 2` calculates the remainder when 7 is divided by 2, which equals `1`. Since `1 = 0` is `FALSE`, the algorithm executes the `ELSE` branch and prints `"ODD"`.
- **Sinhala Explanation:** `7 MOD 2` මගින් 7, 2 න් බෙදූ විට ශේෂය ගණනය කරයි (ශේෂය = 1). 1 = 0 යන්න අසත්‍ය (FALSE) බැවින් `ELSE` කොටස ක්‍රියාත්මක වී `"ODD"` ලෙස මුද්‍රණය වේ.
</details>

#### Q06. What is Pseudo Code? / Pseudo Code (ව්‍යාජ කේත) යනු කුමක්ද?
A. A machine language code that the CPU executes directly / CPU එක මගින් ඍජුවම ක්‍රියාත්මක කරන යන්ත්‍ර භාෂා කේතයක්  
B. An informal, high-level English-like description of an algorithm not tied to any programming language / කිසිදු ක්‍රමලේඛන භාෂාවකට සීමා නොවූ, ඉංග්‍රීසි වචන භාවිතයෙන් ලියනු ලබන ඇල්ගොරිතම විස්තරයකි  
C. An error-free Pascal code / දෝෂ රහිත පැස්කල් කේතයක්  
D. An automated compiler / ස්වයංක්‍රීය කම්පයිලරයක්  

<details>
<summary><b>View Answer & Flashcard Explanation (පිළිතුර සහ ෆ්ලෑෂ්කාඩ් විස්තරය බලන්න)</b></summary>

**Correct Answer:** **B. An informal, high-level English-like description of an algorithm not tied to any programming language / කිසිදු ක්‍රමලේඛන භාෂාවකට සීමා නොවූ, ඉංග්‍රීසි වචන භාවිතයෙන් ලියනු ලබන ඇල්ගොරිතම විස්තරයකි**

- **English Explanation:** Pseudo code is a text-based syntax-independent technique using structured English constructs (`READ`, `PRINT`, `IF..THEN`, `WHILE`) to design algorithms before writing actual program code.
- **Sinhala Explanation:** Pseudo code (ව්‍යාජ කේත) යනු කිසියම් නිශ්චිත පරිගණක භාෂාවක ව්‍යාකරණවලට (Syntax) යටත් නොවී, සාමාන්‍ය ඉංග්‍රීසි වචන භාවිතයෙන් ඇල්ගොරිතමයක තර්කය ලියා දක්වන ක්‍රමයකි.

#### Q16. Which generation of programming languages uses binary code (`0`s and `1`s) directly executable by the CPU? / CPU එක මගින් ඍජුවම ක්‍රියාත්මක කළ හැකි, බිටු (`0` සහ `1`) භාවිතයෙන් ලියනු ලබන ක්‍රමලේඛන භාෂා පරම්පරාව කුමක්ද?

**Correct Answer:** **A. 1st Generation Language (1GL - Machine Language) / 1 වන පරම්පරාවේ භාෂා (යන්ත්‍ර භාෂාව)**

#### Q18. What is the key difference between a Compiler and an Interpreter? / Compiler (කම්පයිලරය) සහ Interpreter (ඉන්ටප්‍රිටරය) අතර ප්‍රධාන වෙනස කුමක්ද?

B. A Compiler translates the entire high-level program into executable object code at once; an Interpreter translates and executes line-by-line / කම්පයිලරය මුළු උසස් පෙළ කේතයම එකවර යන්ත්‍ර කේත බවට පරිවර්තනය කරන අතර ඉන්ටප්‍රිටරය පේළියෙන් පේළිය පරිවර්තනය කර ක්‍රියාත්මක කරයි  
C. Compiler is used for Assembly language / කම්පයිලරය භාවිත කරන්නේ ඇසෙම්බ්ලි භාෂාව සඳහාය  
D. There is no difference / වෙනසක් නොමැත  

<details>
<summary><b>View Answer & Flashcard Explanation (පිළිතුර සහ ෆ්ලෑෂ්කාඩ් විස්තරය බලන්න)</b></summary>

**Correct Answer:** **B. A Compiler translates the entire high-level program into executable object code at once; an Interpreter translates and executes line-by-line / කම්පයිලරය මුළු උසස් පෙළ කේතයම එකවර යන්ත්‍ර කේත බවට පරිවර්තනය කරන අතර ඉන්ටප්‍රිටරය පේළියෙන් පේළිය පරිවර්තනය කර ක්‍රියාත්මක කරයි**
