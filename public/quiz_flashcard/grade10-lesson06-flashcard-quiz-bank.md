### Question 04 / ප්‍රශ්නය 04
* **English:** What is the standard default file extension for documents saved in modern Microsoft Word (2007 and later)?
* **Sinhala:** නූතන Microsoft Word (2007 සහ ඊට පසු) මෘදුකාංගයේ සුරකින ලේඛනයක සම්මත ගොනු විස්තාරණය (File Extension) කුමක්ද?
* **Options:**
  - (A) `.txt`
  - (B) `.docx`
  - (C) `.odt`
  - (D) `.pdf`

<details>
<summary><b>Show Answer & Explanation (පිළිතුර සහ විස්තරය බලන්න)</b></summary>

* **Correct Answer:** **(B) `.docx`**
* **Explanation (විස්තරය):**
  - **[English]:** Modern MS Word uses `.docx` (Office Open XML document). Older MS Word versions (2003 and earlier) used `.doc`. LibreOffice Writer uses `.odt`, plain text uses `.txt`, and Portable Document Format uses `.pdf`.
  - **[Sinhala]:** MS Word 2007 සහ ඊට පසු සංස්කරණවල සුරකින ලේඛනවල ගොනු විස්තාරණය `.docx` වේ. LibreOffice Writer හි `.odt` ද, තනි පෙළ ගොනුවල `.txt` ද, PDF ගොනුවල `.pdf` ද භාවිත වේ.
</details>

### Question 60 / ප්‍රශ්නය 60
* **English:** Which key should be used ONLY when starting a NEW paragraph?
* **Sinhala:** නව ඡේදයක් (New Paragraph) ආරම්භ කිරීමේදී පමණක් එබිය යුතු යතුර කුමක්ද?
* **Options:**
  - (A) `Spacebar`
  - (B) `Enter`
  - (C) `Tab`
  - (D) `Shift`

<details>
<summary><b>Show Answer & Explanation (පිළිතුර සහ විස්තරය බලන්න)</b></summary>

* **Correct Answer:** **(B) `Enter`**
* **Explanation (විස්තරය):**

</details>
