### Question 03 / ප්‍රශ්නය 03
**English:** Which system software loads the Operating System from the hard disk into RAM when the computer is turned on?  
**Sinhala:** පරිගණකය පණගන්වන විට (Booting) දෘඩ තැටියේ ඇති මෙහෙයුම් පද්ධතිය RAM මතකයට පූරණය කරනු ලබන්නේ කුමන වැඩසටහන මගින්ද?

- A) Device Driver / උපාංග ධාවකය
- B) Bootstrap Loader (BIOS/UEFI) / බූට්ස්ට්‍රැප් ලෝඩරය
- C) Disk Defragmenter / ඩිස්ක් ඩීෆ්‍රැග්මන්ටර්
- D) Utility Software / උපයෝගිතා මෘදුකාංගය

<details>
<summary><b>SHOW ANSWER & FLASHCARD BACK (පිළිතුර සහ විස්තරය බලන්න)</b></summary>

**Correct Answer:** **B) Bootstrap Loader (BIOS/UEFI)**

**Explanation (විස්තරය):**
- **English:** When a computer boots up, the Bootstrap Loader program stored in non-volatile ROM (BIOS/UEFI) executes, performs POST (Power-On Self-Test), locates the OS on secondary storage, and loads it into primary RAM.
- **Sinhala:** පරිගණකය පණගැන්වීමේදී, ROM මතකයේ තැන්පත් කර ඇති Bootstrap Loader වැඩසටහන මගින් POST පරික්ෂාව සිදුකර, දෘඩ තැටියේ ඇති මෙහෙයුම් පද්ධතිය RAM මතකයට පූරණය කරයි.
</details>

### Question 05 / ප්‍රශ්නය 05
**English:** Which category of software license allows users to access, modify, and redistribute the source code freely?  
**Sinhala:** මෘදුකාංගයක මූලාශ්‍ර කේතය (Source Code) නිදහසේ අධ්‍යයනය කිරීමට, වෙනස් කිරීමට සහ නැවත බෙදා හැරීමට පරිශීලකයන්ට ඉඩ සලසන මෘදුකාංග බලපත්‍ර වර්ගය කුමක්ද?

- A) Proprietary Software / හිමිකාර මෘදුකාංග
- B) Free and Open Source Software (FOSS) / නිදහස් හා විවෘත මූලාශ්‍ර මෘදුකාංග
- C) Shareware / කොන්දේසි සහිත නොමිලේ මෘදුකාංග

<details>
<summary><b>SHOW ANSWER & FLASHCARD BACK (පිළිතුර සහ විස්තරය බලන්න)</b></summary>

- A) Dual-Booting requires selecting one OS at computer startup, whereas Virtual Machines allow running a guest OS inside an application window while the host OS is running. / Dual-Booting හිදී පරිගණකය පණගන්වන විට එක් OS එකක් තෝරාගත යුතු අතර, Virtual Machine මගින් ප්‍රධාන OS එක ධාවනය වන අතරතුර වෙනත් OS එකක් කවුළුවක් තුළ ධාවනය කළ හැක.

- C) Virtual Machines erase all user data permanently. / Virtual Machine මගින් දත්ත මකා දමයි.
- D) Dual-Booting works only on mobile phones. / Dual-Booting ජංගම දුරකථනවලට පමණි.
