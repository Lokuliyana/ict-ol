### 🎴 Question / Flashcard #03
**English:** Which system software loads the Operating System from the hard disk into RAM when the computer is turned on?  
**Sinhala:** පරිගණකය පණගන්වන විට (Booting) දෘඩ තැටියේ ඇති මෙහෙයුම් පද්ධතිය RAM මතකයට පූරණය කරනු ලබන්නේ කුමන වැඩසටහන මගින්ද?

- (A) Device Driver / උපාංග ධාවකය
- (B) Bootstrap Loader (BIOS/UEFI) / බූට්ස්ට්‍රැප් ලෝඩරය
- (C) Disk Defragmenter / ඩිස්ක් ඩීෆ්‍රැග්මන්ටර්
- (D) Utility Software / උපයෝගිතා මෘදුකාංගය

**Correct Answer / නිවැරදි පිළිතුර:** **(B)**

</details>

### 🎴 Question / Flashcard #60
**English:** What is the main difference between Dual-Booting and Virtual Machines (VMs) for running two Operating Systems on one computer?  
**Sinhala:** එක පරිගණකයක මෙහෙයුම් පද්ධති දෙකක් ධාවනය කිරීමේදී Dual-Booting සහ Virtual Machines (VM) අතර ප්‍රධාන වෙනස කුමක්ද?

- (A) Dual-Booting requires selecting one OS at computer startup, whereas Virtual Machines allow running a guest OS inside an application window while the host OS is running. / Dual-Booting හිදී පරිගණකය පණගන්වන විට එක් OS එකක් තෝරාගත යුතු අතර, Virtual Machine මගින් ප්‍රධාන OS එක ධාවනය වන අතරතුර වෙනත් OS එකක් කවුළුවක් තුළ ධාවනය කළ හැක.
- (B) Dual-Booting does not use a hard disk. / Dual-Booting සඳහා දෘඩ තැටියක් අවශ්‍ය නැත.
- (C) Virtual Machines erase all user data permanently. / Virtual Machine මගින් දත්ත මකා දමයි.
- (D) Dual-Booting works only on mobile phones. / Dual-Booting ජංගම දුරකථනවලට පමණි.

**Correct Answer / නිවැරදි පිළිතුර:** **(A)**

**Explanation & Flashcard Back / විස්තරය:**
- **English:** Key Term: Dual-Booting vs Virtual Machines. Dual-boot allocates separate disk partitions for two OSs (e.g. Windows and Linux) selected at startup. Virtualization software (e.g. VirtualBox) runs a secondary OS concurrently as a guest VM inside the main OS. Example: Dual-booting Windows 11 & Ubuntu on disk partitions vs running VirtualBox.

Virtual Machine එකකදී ප්‍රධාන OS එක මත තවත් OS එකක් කවුළුවක් තුළ එකවර ධාවනය කළ හැක. උදාහරණ: පරිගණකය පණගැන්වීමේදී OS තේරීම (Dual-boot) සහ කවුළුවක් තුළ OS ධාවනය (VM).
