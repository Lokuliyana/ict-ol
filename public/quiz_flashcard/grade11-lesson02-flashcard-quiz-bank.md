#### Q01. What is an Information System?
**ප්‍රශ්නය 01. තොරතුරු පද්ධතියක් යනු කුමක්ද?**
- A) A collection of hardware components without software. / මෘදුකාංග නොමැති හුදෙක් දෘඩාංග එකතුවකි.
- B) An organized set of components (hardware, software, data, people, procedures) working together to process data into information. / දත්ත තොරතුරු බවට පත් කිරීම සඳහා එකිනෙක හා සම්බන්ධව ක්‍රියාකරන දෘඩාංග, මෘදුකාංග, දත්ත, පිරිස් සහ ක්‍රියාපටිපාටිවලින් සමන්විත සංවිධානාත්මක පද්ධතියකි.
- C) A programming language used to build operating systems. / මෙහෙයුම් පද්ධති තැනීමට භාවිත කරන ක්‍රමලේඛන භාෂාවකි.
- D) A database table that stores user passwords. / පරිශීලක මුරපද ගබඩා කරන දත්ත සමුදා වගුවකි.

#### Q04. Why is SDLC modeled as a "Cycle" rather than a linear one-way path?
**ප්‍රශ්නය 04. SDLC යන්න සරල රේඛීය මාර්ගයක් වෙනුවට "චක්‍රයක්" (Cycle) ලෙස නිරූපණය කරන්නේ මන්ද?**
- A) Because the hardware burns out after one year. / වසරකට පසු දෘඩාංග දැවී යන බැවිනි.
- B) Because system requirements change over time, requiring continuous evaluation, updates, and iterative maintenance cycles. / කාලයත් සමඟ පද්ධති අවශ්‍යතා වෙනස් වන බැවින්, අඛණ්ඩ ඇගයීම්, යාවත්කාලීන කිරීම් සහ නඩත්තු චක්‍ර අවශ්‍ය වන බැවිනි.
- C) Because coding languages loop endlessly. / ක්‍රමලේඛන භාෂා අනන්ත ලෙස ලූප් වන බැවිනි.
- D) Because computers process numbers in binary loops. / පරිගණක ද්විමය ලූප් මගින් සංඛ්‍යා සකසන බැවිනි.

<summary><b>View Answer & Flashcard Explanation (පිළිතුර සහ ෆ්ලෑෂ්කාඩ් විස්තරය බලන්න)</b></summary>

* **Correct Answer / නිවැරදි පිළිතුර:** **B) Because system requirements change over time, requiring continuous evaluation, updates, and iterative maintenance cycles.**
* **Explanation / විස්තරය:**
  - **[English]:** A system is rarely finished permanently. Changing business rules, tech advances, and user feedback trigger new iterations of the SDLC.
  - **[Sinhala]:** පද්ධතියක් කිසිවිටෙකත් ස්ථිරවම අවසන් නොවේ. ව්‍යාපාරික නීති, තාක්ෂණික දියුණුව සහ පරිශීලක ප්‍රතිචාර නිසා නව SDLC චක්‍ර නැවත ආරම්භ වේ.

#### Q06. What is a "Functional Requirement"?
