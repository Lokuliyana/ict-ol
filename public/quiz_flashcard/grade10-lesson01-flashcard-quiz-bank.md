## SECTION 1: Data & Information Concepts (දත්ත සහ තොරතුරු සංකල්ප)

### 🎴 Question / Flashcard #01
**Question / ප්‍රශ්නය:**
What is the fundamental definition of 'Data' in ICT?
තොරතුරු සහ සන්නිවේදන තාක්ෂණයේදී 'දත්ත' (Data) යන්නෙහි මූලික අර්ථ දැක්වීම කුමක්ද?

- (A) Processed results ready for decision making / තීරණ ගැනීම සඳහා සකස් කළ ප්‍රතිඵල
- (B) Unprocessed raw facts, figures, or symbols / සැකසීමට ලක් නොකළ අමු තොරතුරු, සංඛ්‍යා හෝ සංකේත
- (C) Output displayed on a computer screen / පරිගණක තිරයේ දර්ශනය වන ප්‍රතිදාන
- (D) Stored electronic reports / ගබඩා කර ඇති ඉලෙක්ට්‍රොනික වාර්තා

**Correct Answer / නිවැරදි පිළිතුර:** **(B)**

**Explanation & Flashcard Back / විස්තරය:**
* **English:** Data refers to raw, unorganized, unprocessed facts, figures, letters, or symbols that do not convey a specific context or meaning on their own (e.g., individual numbers like 85, 90, 72).
* **සිංහල:** දත්ත යනු සන්දර්භයක් හෝ අර්ථයක් නොමැති, ක්‍රියාවලියකට ලක් නොකළ අමු සංඛ්‍යා, අක්ෂර, රූප හෝ සංකේත වේ (උදා: 85, 90, 72 වැනි හුදකලා අංක).

### 🎴 Question / Flashcard #02
**Question / ප්‍රශ්නය:**
What is the definition of 'Information' in ICT?
තොරතුරු සහ සන්නිවේදන තාක්ෂණයේදී 'තොරතුරු' (Information) යන්නෙහි අර්ථ දැක්වීම කුමක්ද?

- (A) Raw figures collected from surveys / සමීක්ෂණවලින් ලබාගත් අමු සංඛ්‍යා
- (B) Hardware devices inside a system / පද්ධතියක් තුළ ඇති දෘඩාංග උපාංග
- (C) Processed data that provides meaning and context / සන්දර්භයක් සහ අර්ථයක් ලැබෙන සේ සකස් කරන ලද දත්ත
- (D) Unorganized student test marks / සංවිධානය නොකළ ශිෂ්‍ය පරීක්ෂණ ලකුණු

**Correct Answer / නිවැරදි පිළිතුර:** **(C)**

**Explanation & Flashcard Back / විස්තරය:**
* **English:** Information is data that has been processed, organized, structured, or contextualized so that it becomes meaningful, understandable, and useful for decision making.
* **සිංහල:** තොරතුරු යනු තීරණ ගැනීම සඳහා ප්‍රයෝජනවත් වන පරිදි සකසන ලද, සංවිධානය කරන ලද සහ අර්ථවත් කරන ලද දත්ත වේ.

### 🎴 Question / Flashcard #03
**Question / ප්‍රශ්නය:**
Which of the following is an example of 'Data'?
පහත සඳහන් දෑ අතරින් 'දත්ත' සඳහා උදාහරණයක් වන්නේ කුමක්ද?

- (A) Total term test marks of a student (e.g., 480) / ශිෂ්‍යයෙකුගේ වාර විභාගයේ මුළු ලකුණු (උදා: 480)
- (B) Average temperature of a month / මාසයක සාමාන්‍ය උෂ්ණත්වය
- (C) The individual mark '85' obtained for Mathematics / ගණිතය විෂය සඳහා ලබාගත් '85' යන හුදකලා ලකුණ
- (D) Highest score report in a class / පන්තියක ඉහළම ලකුණු වාර්තාව

**Correct Answer / නිවැරදි පිළිතුර:** **(C)**

**Explanation & Flashcard Back / විස්තරය:**
* **English:** The standalone number '85' is raw data because without context (like student name, subject, or total marks), it conveys no meaningful decision-making value. Total marks and averages are processed information.
* **සිංහල:** '85' යන්න හුදකලා අගයක් බැවින් එය අමු දත්තයකි. මන්දයත් එය කාගේ ලකුණක්ද, කුමන විෂයටද යන්න පැහැදිලි නැති බැවිනි. මුළු ලකුණු සහ සාමාන්‍යය යනු සැකසූ තොරතුරු වේ.

### 🎴 Question / Flashcard #04
**Question / ප්‍රශ්නය:**
Which of the following represents 'Information'?
පහත සඳහන් දෑ අතරින් 'තොරතුරු' නිරූපණය කරන්නේ කුමක්ද?

- (A) The digits 2, 0, 0, 5, 1, 2, 8 / 2, 0, 0, 5, 1, 2, 8 යන ඉලක්කම්
- (B) Student's position in class: "1st Place" / පන්තියේ ශිෂ්‍යයාගේ ස්ථානය: "1 වන ස්ථානය"
- (C) A list of unsorted numbers / අනුපිළිවෙලට සකස් නොකළ සංඛ්‍යා ලැයිස්තුවක්
- (D) Unprocessed survey responses / සකස් නොකළ සමීක්ෂණ ප්‍රශ්නාවලී පිළිතුරු

**Correct Answer / නිවැරදි පිළිතුර:** **(B)**

**Explanation & Flashcard Back / විස්තරය:**
* **English:** "1st Place" is information derived after processing (sorting and comparing) the total marks of all students in the class.
* **සිංහල:** "1 වන ස්ථානය" යනු පන්තියේ සියලුම ළමුන්ගේ ලකුණු එකතු කර, සසඳා, අනුපිළිවෙලට සකස් කිරීමෙන් පසු ලබාගන්නා අර්ථවත් තොරතුරකි.

### 🎴 Question / Flashcard #05
**Question / ප්‍රශ්නය:**
What is the core relationship between Data, Processing, and Information?
දත්ත, ක්‍රියාවලිය (Processing) සහ තොරතුරු අතර පවතින මූලික සබඳතාව කුමක්ද?

- (A) Information + Processing = Data
- (B) Data + Information = Processing
- (C) Data → Processing → Information
- (D) Processing → Data → Information

**Correct Answer / නිවැරදි පිළිතුර:** **(C)**

**Explanation & Flashcard Back / විස්තරය:**
* **English:** Raw Data enters as Input, undergoes Processing (calculations, sorting, filtering), and yields Information as Output.
* **සිංහල:** අමු දත්ත ඇතුළත් කිරීම් (Input) ලෙස ලබාදී, ක්‍රියාවලියකට (Processing) ලක්කිරීමෙන් පසු තොරතුරු (Information) ප්‍රතිදානය ලෙස ලැබේ.

### 🎴 Question / Flashcard #06
**Question / ප්‍රශ්නය:**
Analyzing a National Identity Card (NIC) number like "200523401234" to extract the birth year (2005) is an example of:
"200523401234" වැනි ජාතික හැඳුනුම්පත් අංකයකින් උපන් වර්ෂය (2005) ලබා ගැනීම කුමකට උදාහරණයක්ද?

- (A) Converting Information into Data / තොරතුරු දත්ත බවට පත් කිරීම
- (B) Processing Data into Information / දත්ත තොරතුරු බවට සකස් කිරීම (Processing)
- (C) Data Deletion / දත්ත මකා දැමීම
- (D) Hardware Assembly / දෘඩාංග එකලස් කිරීම

**Correct Answer / නිවැරදි පිළිතුර:** **(B)**

**Explanation & Flashcard Back / විස්තරය:**
* **English:** The raw NIC string is Data. Extracting the birth year, gender, and age involves a Processing logic that converts that string into useful Information.
* **සිංහල:** හැඳුනුම්පත් අංකය අමු දත්තයක් වන අතර, එයින් උපන් වර්ෂය, ස්ත්‍රී/පුරුෂ භාවය සහ වයස ලබා ගැනීම දත්ත තොරතුරු බවට පත් කිරීමේ ක්‍රියාවලියකි (Processing).

### 🎴 Question / Flashcard #07
**Question / ප්‍රශ්නය:**
Which of the following is NOT an attribute of raw data?
පහත සඳහන් දෑ අතරින් අමු දත්තවල ලක්ෂණයක් නො වන්නේ කුමක්ද?

- (A) Lacks context on its own / තනිවම පැවති විට සන්දර්භයක් නොමැත
- (B) Directly suitable for making major administrative decisions / පරිපාලනමය තීරණ ගැනීමට සෘජුවම සුදුසු වේ
- (C) Serves as the input for a system / පද්ධතියක ඇතුළත් කිරීම් (Input) ලෙස ක්‍රියා කරයි
- (D) Can be numbers, letters, images, or audio / සංඛ්‍යා, අක්ෂර, රූප හෝ ශ්‍රව්‍ය විය හැක

**Correct Answer / නිවැරදි පිළිතුර:** **(B)**

**Explanation & Flashcard Back / විස්තරය:**
* **English:** Raw data is NOT directly suitable for decision making because it is unorganized and lacks meaning. Decisions require processed Information.
* **සිංහල:** අමු දත්ත තනිවම අර්ථවත් නොවන බැවින් ඒවා භාවිතයෙන් සෘජුවම තීරණ ගත නොහැක. තීරණ ගැනීම සඳහා දත්ත තොරතුරු බවට සකස් කළ යුතුය.

### 🎴 Question / Flashcard #08
**Question / ප්‍රශ්නය:**
Which operation converts raw marks (70, 80, 90) into the average mark (80)?
අමු ලකුණු (70, 80, 90) සාමාන්‍ය ලකුණ (80) බවට පත් කරන මෙහෙයුම කුමක්ද?

- (A) Data Collection / දත්ත රැස්කිරීම
- (B) Data Processing / දත්ත සැකසීම (Processing)
- (C) Information Output / තොරතුරු ප්‍රතිදානය
- (D) Data Storage / දත්ත ගබඩා කිරීම

**Correct Answer / නිවැරදි පිළිතුර:** **(B)**

**Explanation & Flashcard Back / විස්තරය:**
