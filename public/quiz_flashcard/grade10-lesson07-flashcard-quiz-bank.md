### 🎴 Question / Flashcard #01
**Question / ප්‍රශ්නය:**
What is the primary purpose of electronic spreadsheet software?
ඉලෙක්ට්‍රොනික පැතුරුම්පත් මෘදුකාංගයක ප්‍රධාන අරමුණ කුමක්ද?

- (A) Editing high-resolution digital photographs / ඉහළ විභේදනයක් සහිත ඩිජිටල් ඡායාරූප සංස්කරණය කිරීම
- (B) Organizing, calculating, and analyzing numerical data in grid rows and columns / පේළි සහ තීරු සහිත ජාලකයක සංඛ්‍යාත්මක දත්ත සංවිධානය කිරීම, ගණනය කිරීම සහ විශ්ලේෂණය කිරීම
- (C) Creating vector animations and 3D graphics / දෛශික සජීවීකරණ සහ ත්‍රිමාණ චිත්‍රක නිර්මාණය කිරීම
- (D) Designing relational database schemas / සම්බන්ධතා දත්ත සමුදා සැලසුම් නිර්මාණය කිරීම

**Correct Answer / නිවැරදි පිළිතුර:** **(B)**

**Explanation & Flashcard Back / විස්තරය:**
* **English:** Spreadsheet software (like MS Excel, LibreOffice Calc) is designed to organize, calculate, and analyze numerical data efficiently using grids of rows and columns.
* **සිංහල:** පැතුරුම්පත් මෘදුකාංග (MS Excel, LibreOffice Calc වැනි) නිර්මාණය කර ඇත්තේ පේළි සහ තීරු ජාලක භාවිතයෙන් සංඛ්‍යාත්මක දත්ත කාර්යක්ෂමව සංවිධානය කිරීමට, ගණනය කිරීමට සහ විශ්ලේෂණය කිරීමටය.

### 🎴 Question / Flashcard #02
**Question / ප්‍රශ්නය:**
Which of the following is a Free and Open Source Software (FOSS) electronic spreadsheet application?
පහත සඳහන් දෑ අතරින් නිදහස් හා විවෘත මූලාශ්‍ර (FOSS) ඉලෙක්ට්‍රොනික පැතුරුම්පත් මෘදුකාංගයක් වන්නේ කුමක්ද?

- (A) Microsoft Excel / මයික්‍රොසොෆ්ට් එක්සෙල්
- (B) Apple Numbers / ඇපල් නම්බර්ස්
- (C) LibreOffice Calc / ලිබ්‍රේඔෆිස් කැල්ක්
- (D) Google Sheets / ගූගල් ෂීට්ස්

**Correct Answer / නිවැරදි පිළිතුර:** **(C)**

**Explanation & Flashcard Back / විස්තරය:**
* **English:** LibreOffice Calc is a FOSS spreadsheet tool. MS Excel and Apple Numbers are proprietary software, while Google Sheets is a cloud-based web application.
* **සිංහල:** LibreOffice Calc යනු FOSS පැතුරුම්පත් මෘදුකාංගයකි. MS Excel සහ Apple Numbers හිමිකාර (Proprietary) වන අතර Google Sheets යනු වලාකුළු මත පදනම් වූ (Cloud-based) වෙබ් යෙදුමකි.

### 🎴 Question / Flashcard #03
**Question / ප්‍රශ්නය:**
In a spreadsheet, what is the intersection of a single row and a single column called?
පැතුරුම්පතක තනි තීරුවක් සහ තනි පේළියක් එකිනෙක ඡේදනය වන ස්ථානය හඳුන්වන්නේ කුමක්ද?

- (A) Workbook / වැඩපොත
- (B) Gridline / ජාල රේඛාව
- (C) Cell / සෛලය (Cell)
- (D) Formula Bar / සූත්‍ර තීරුව

**Correct Answer / නිවැරදි පිළිතුර:** **(C)**

**Explanation & Flashcard Back / විස්තරය:**
* **English:** A Cell is the basic unit of a worksheet formed by the intersection of a column and a row (e.g., cell B5).
* **සිංහල:** සෛලයක් (Cell) යනු තීරුවක් සහ පේළියක් එකිනෙක ඡේදනය වීමෙන් සෑදෙන පැතුරුම්පතක මූලික ඒකකයයි (උදා: B5 සෛලය).

### 🎴 Question / Flashcard #04
**Question / ප්‍රශ්නය:**
How are columns and rows identified in a standard electronic spreadsheet?
සම්මත ඉලෙක්ට්‍රොනික පැතුරුම්පතක තීරු (Columns) සහ පේළි (Rows) හඳුනා ගනු ලබන්නේ කෙසේද?

- (A) Columns by numbers (1, 2, 3), Rows by letters (A, B, C) / තීරු අංකවලින් (1, 2, 3), පේළි අක්ෂරවලින් (A, B, C)
- (B) Columns by letters (A, B, C), Rows by numbers (1, 2, 3) / තීරු අක්ෂරවලින් (A, B, C), පේළි අංකවලින් (1, 2, 3)
- (C) Columns by Roman numerals (I, II), Rows by letters / තීරු රෝම ඉලක්කම්වලින්, පේළි අක්ෂරවලින්
- (D) Both columns and rows are identified by numbers only / තීරු සහ පේළි දෙකම අංකවලින් පමණි

**Correct Answer / නිවැරදි පිළිතුර:** **(B)**

**Explanation & Flashcard Back / විස්තරය:**
* **English:** Columns are designated by letters (A, B, C... Z, AA, AB...), while rows are designated by numbers (1, 2, 3...).
* **සිංහල:** තීරු අක්ෂරවලින්ද (A, B, C...), පේළි සංඛ්‍යාවලින්ද (1, 2, 3...) හඳුනාගනු ලබයි.

### 🎴 Question / Flashcard #05
**Question / ප්‍රශ්නය:**

**Question / ප්‍රශ්නය:**
What is the default file extension for a workbook saved in Microsoft Excel 2016/2019?
Microsoft Excel 2016/2019 හි සුරකින ලද වැඩපොතක පෙරනිමි ගොනු දිගුව (File extension) කුමක්ද?
