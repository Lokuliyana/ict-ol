### Question 01
**[English]:** Which of the following best defines a "Website"?  
**[සිංහල]:** "වෙබ් අඩවියක් (Website)" යන්න වඩාත්ම නිවැරදිව අර්ථ දක්වන්නේ පහත සඳහන් කුමක්ද?  
- (A) A single digital document containing HTML code only. / HTML කේත පමණක් අඩංගු තනි ඩිජිටල් ලේඛනයක්.  
- (B) A collection of related web pages hosted under a single domain name on a web server. / එක් වසම් නාමයක් (Domain Name) යටතේ වෙබ් සේවාදායකයක ගබඩා කර ඇති එකිනෙකට සම්බන්ධිත වෙබ් පිටු සමූහයකි.  
- (C) A software program used to search the internet. / අන්තර්ජාලය සෙවීම සඳහා භාවිත වන මෘදුකාංග වැඩසටහනක්.  
- (D) A physical storage device storing media files. / මාධ්‍ය ගොනු ගබඩා කරන භෞතික ආචයන උපකරණයක්.

### Question 02
**[English]:** What is the main characteristic of a **Static Web Page** compared to a Dynamic Web Page?  
**[සිංහල]:** ගතික වෙබ් පිටුවකට (Dynamic Web Page) සාපේක්ෂව **ස්ථිතික වෙබ් පිටුවක (Static Web Page)** ප්‍රධාන ලක්ෂණය වන්නේ කුමක්ද?  
- (A) Content changes automatically based on database queries and time. / දත්ත සමුදා විමසුම් සහ වේලාව මත අන්තර්ගතය ස්වයංක්‍රීයව වෙනස් වේ.  
- (B) Content remains fixed for all users until manually edited in code. / කේතය අතින් වෙනස් කරන තෙක් සියලු පරිශීලකයන්ට එකම අන්තර්ගතයක් ස්ථාවරව පෙනේ.  
- (C) It requires complex server-side scripting languages like PHP or ASP.NET. / ඊට PHP හෝ ASP.NET වැනි සංකීර්ණ සේවාදායක පස මෘදුකාංග කේත අවශ්‍ය වේ.  
- (D) It allows users to create user profiles and process online payments. / පරිශීලක ගිණුම් සෑදීමට සහ මාර්ගගත ගෙවීම් කිරීමට ඉඩ සලසයි.  

<details>
<summary><b>View Answer & Flashcard Explanation / පිළිතුර සහ ෆ්ලෑෂ්කාඩ් පැහැදිලි කිරීම</b></summary>

**Correct Answer:** **(B) Content remains fixed for all users until manually edited in code.**

**Explanation / පැහැදිලි කිරීම:**  
- **[English]:** Static web pages are built using plain HTML/CSS. Every visitor sees identical content because there is no backend database connection. Dynamic web pages (e.g. Facebook, Online Banking) generate personalized content using server-side databases (PHP/MySQL).  
- **[සිංහල]:** ස්ථිතික වෙබ් පිටුවල අන්තර්ගතය HTML/CSS මගින් සකසන අතර කේතය වෙනස් කරන තෙක් සෑම පරිශීලකයෙකුටම පෙනෙන්නේ එකම අන්තර්ගතයයි. දත්ත සමුදා හා සම්බන්ධ නොවෙයි.
</details>

**[සිංහල]:** **HTML** යන්නෙහි සම්පූර්ණ නාමය වන්නේ කුමක්ද?  
- (A) HyperText Markup Language  
- (B) High-Tech Transfer Markup Language  
- (C) Hyperlink Text Management Language

<summary><b>View Answer & Flashcard Explanation / පිළිතුර සහ ෆ්ලෑෂ්කාඩ් පැහැදිලි කිරීම</b></summary>

- (D) Container tags are only used inside the `<head>` section. / කන්ටේනර් ටැග් භාවිත වන්නේ `<head>` තුළ පමණි.

### 2. HTML Table Merging Attributes

| Attribute (ගුණාංගය) | Function in English | භාවිතය (සිංහල) | Example Code Syntax |
