### Q01 | Question 01
**English:** What is the fundamental definition of a "Database"?  
**සිංහල:** "දත්ත සමුදායක්" (Database) යන්නෙහි මූලික අර්ථ දැක්වීම කුමක්ද?  
- (A) An unstructured collection of random digital documents stored in a folder
- (B) An organized collection of logically related data structured for easy access, retrieval, and management
- (C) A computer programming language used exclusively to calculate mathematical statistics
- (D) A hardware storage peripheral designed solely for backing up operating systems

<summary><b>View Answer & Flashcard Explanation / පිළිතුර සහ පැහැදිලි කිරීම බලන්න</b></summary>

### Q02 | Question 02
**English:** Which sequence correctly represents the organizational hierarchy of data in computer systems from smallest to largest?  
**සිංහල:** පරිගණක පද්ධති තුළ දත්ත ධුරාවලිය කුඩාම ඒකකයේ සිට විශාලතම ඒකකය දක්වා නිවැරදිව පෙළගස්වා ඇති පිළිවෙළ කුමක්ද?  
- (A) Bit → Byte → Field → Record → Table → Database
- (B) Byte → Bit → Record → Field → Table → Database
- (C) Bit → Field → Byte → Record → Database → Table
- (D) Field → Record → Byte → Bit → Table → Database

<details>
<summary><b>View Answer & Flashcard Explanation / පිළිතුර සහ පැහැදිලි කිරීම බලන්න</b></summary>

**Correct Answer:** **(A) Bit → Byte → Field → Record → Table → Database**

**Detailed Explanation (පැහැදිලි කිරීම):**
- **English:** The computer data hierarchy ascends strictly from: Bit (0 or 1) → Byte (character) → Field (attribute/column) → Record (tuple/row) → Table (relation/file) → Database.
- **සිංහල:** පරිගණක දත්ත ධුරාවලිය කුඩාම ඒකකයේ සිට ඉහළට පෙළගැසෙන්නේ: බිටුව (0 හෝ 1) → බයිටය (අක්ෂරය) → ක්ෂේත්‍රය (තීරුව) → ලේඛනය (පේළිය) → වගුව (සබඳතාව) → දත්ත සමුදාය යන අනුපිළිවෙළටයි.
</details>

### Q03 | Question 03
**English:** In a relational database table, what is a single horizontal row containing data for one entity called?  
**සිංහල:** සම්බන්ධතා දත්ත සමුදා වගුවක, එක් එන්ටිටියකට අයත් දත්ත අඩංගු තනි තිරස් පේළියක් හඳුන්වන්නේ කුමක් ලෙසද?  
- (A) Field or Attribute
- (B) Record or Tuple
- (C) Domain or Data Type
- (D) Schema or View

<details>
<summary><b>View Answer & Flashcard Explanation / පිළිතුර සහ පැහැදිලි කිරීම බලන්න</b></summary>

**Correct Answer:** **(B) Record or Tuple**

**Detailed Explanation (පැහැදිලි කිරීම):**
- **English:** A horizontal row in a relational table represents a single complete instance of an entity and is formally known as a Record or Tuple. Columns are called Fields or Attributes.
- **සිංහල:** වගුවක තිරස් පේළියක් තනි සම්පූර්ණ අවස්ථාවක් නිරූපණය කරන අතර එය ලේඛනයක් (Record) හෝ ටූපලයක් (Tuple) ලෙස හැඳින්වේ. සිරස් තීරු ක්ෂේත්‍ර (Fields) හෝ විශේෂණ (Attributes) ලෙස හැඳින්වේ.
</details>

### Q04 | Question 04
**English:** In relational database terminology, what is a vertical column that stores a specific property or characteristic of an entity?  
**සිංහල:** සම්බන්ධතා දත්ත සමුදා පාරිභාෂික ශබ්දමාලාවට අනුව, එන්ටිටියක නිශ්චිත ගුණාංගයක් ගබඩා කරන සිරස් තීරුවක් හඳුන්වන්නේ කෙසේද?  
- (A) Record
- (B) Tuple
- (C) Attribute or Field
- (D) Relation

<details>
<summary><b>View Answer & Flashcard Explanation / පිළිතුර සහ පැහැදිලි කිරීම බලන්න</b></summary>

**Correct Answer:** **(C) Attribute or Field**

**Detailed Explanation (පැහැදිලි කිරීම):**
- **English:** A vertical column in a table stores a specific descriptor of an entity (such as `DateOfBirth` or `ContactNo`) and is termed an Attribute or Field.
- **සිංහල:** වගුවක සිරස් තීරුවක් මගින් එන්ටිටියක යම් නිශ්චිත ලක්ෂණයක් (උදා: `DateOfBirth` හෝ `ContactNo`) ගබඩා කරන අතර එය විශේෂණයක් (Attribute) හෝ ක්ෂේත්‍රයක් (Field) ලෙස හඳුන්වනු ලබයි.
</details>

### Q05 | Question 05
**English:** Which key in a relational database uniquely identifies every record in a table and cannot contain NULL values?  
**සිංහල:** වගුවක සෑම ලේඛනයක්ම අනන්‍යව හඳුනාගන්නා අතර හිස් (NULL) අගයන් පැවතිය නොහැකි යතුර කුමක්ද?  
- (A) Foreign Key
- (B) Primary Key
- (C) Secondary Index
- (D) Composite Attribute

<details>
<summary><b>View Answer & Flashcard Explanation / පිළිතුර සහ පැහැදිලි කිරීම බලන්න</b></summary>

**Correct Answer:** **(B) Primary Key**

**Detailed Explanation (පැහැදිලි කිරීම):**
- **English:** A Primary Key must satisfy two strict integrity constraints: Uniqueness (no duplicate keys) and Entity Integrity (it cannot contain NULL values).
- **සිංහල:** ප්‍රාථමික යතුරක් (Primary Key) අනිවාර්යයෙන්ම අනන්‍ය විය යුතු අතර (Uniqueness) කිසිවිටෙකත් හිස් (NULL) අගයන් නොපැවතිය යුතුය (Entity Integrity).
</details>

### Q06 | Question 06
**English:** What is a field in a relational table that corresponds to and matches the Primary Key of another table?  
**සිංහල:** වෙනත් වගුවක ප්‍රාථමික යතුරට අනුරූප වෙමින් වගු දෙක අතර සබඳතාව ගොඩනගන ක්ෂේත්‍රය කුමක්ද?  
- (A) Primary Key
- (B) Candidate Key
- (C) Foreign Key
- (D) Super Key

<details>
<summary><b>View Answer & Flashcard Explanation / පිළිතුර සහ පැහැදිලි කිරීම බලන්න</b></summary>

**Correct Answer:** **(C) Foreign Key**

**Detailed Explanation (පැහැදිලි කිරීම):**
- **English:** A Foreign Key is a field in a referencing (child) table that matches the Primary Key of a referenced (parent) table, establishing a relational link between them.
- **සිංහල:** ආගන්තුක යතුරක් (Foreign Key) යනු වෙනත් මව් වගුවක ප්‍රාථමික යතුර හා සම්බන්ධ වෙමින් වගු අතර තර්කානුකූල සබඳතාවක් ගොඩනැගීමට යොදාගන්නා ක්ෂේත්‍රයයි.
</details>

### Q07 | Question 07
**English:** What is a Primary Key called when it is formed by combining two or more fields together to uniquely identify a record?  
**සිංහල:** වගුවක ලේඛනයක් අනන්‍යව හඳුනාගැනීම සඳහා ක්ෂේත්‍ර දෙකක් හෝ වැඩි ගණනක් එකතු කර සාදාගන්නා ප්‍රාථමික යතුර හඳුන්වන්නේ කුමක් ලෙසද?  
- (A) Alternate Key
- (B) Foreign Key
- (C) Composite Primary Key
- (D) Secondary Key

<details>
<summary><b>View Answer & Flashcard Explanation / පිළිතුර සහ පැහැදිලි කිරීම බලන්න</b></summary>

**Correct Answer:** **(C) Composite Primary Key**

**Detailed Explanation (පැහැදිලි කිරීම):**
- **English:** When no single attribute can guarantee uniqueness, two or more attributes are joined together to form a Composite Primary Key.
- **සිංහල:** තනි ක්ෂේත්‍රයකින් වාර්තාවක් අනන්‍යව හඳුනාගත නොහැකි වූ විට, ක්ෂේත්‍ර දෙකක් හෝ කිහිපයක් ඒකාබද්ධ කර සාදාගන්නා ප්‍රාථමික යතුර සංයුක්ත ප්‍රාථමික යතුරක් (Composite Primary Key) ලෙස හැඳින්වේ.
</details>

### Q08 | Question 08
**English:** What are any candidate keys that are NOT selected as the Primary Key called?  
**සිංහල:** වගුවක ප්‍රාථමික යතුර ලෙස තෝරා නොගත් ඉතිරි අපේක්ෂක යතුරු හඳුන්වනු ලබන්නේ කිනම් නමකින්ද?  
- (A) Foreign Keys
- (B) Alternate Keys
- (C) Composite Keys
- (D) Primary Keys

<details>
<summary><b>View Answer & Flashcard Explanation / පිළිතුර සහ පැහැදිලි කිරීම බලන්න</b></summary>

**Correct Answer:** **(B) Alternate Keys**
