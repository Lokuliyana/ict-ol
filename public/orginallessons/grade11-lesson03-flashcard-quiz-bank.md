### Question 01
**Which of the following best defines a Computer Network?**  
**පහත සඳහන් දැයින් පරිගණක ජාලයක් (Computer Network) වඩාත්ම නිවැරදිව අර්ථ දක්වන්නේ කුමක්ද?**

- (A) A single supercomputer connected to multiple monitors / බහු මොනිටරවලට සම්බන්ධ කළ තනි සුපිරි පරිගණකයක්
- (B) Two or more computers connected together to share resources and data / සම්පත් සහ දත්ත හුවමාරු කර ගැනීම සඳහා එකිනෙකට සම්බන්ධ කළ පරිගණක දෙකක් හෝ වැඩි ගණනක්
- (C) A software program that manages internal computer files / පරිගණකයේ අභ්‍යන්තර ගොනු කළමනාකරණය කරන මෘදුකාංග වැඩසටහනක්
- (D) An electrical circuit that powers computer hardware / පරිගණක දෘඩාංග සඳහා බලය සපයන විදුලි පරිපථයක්

### Question 02
**Which network geographical classification covers a small physical area such as a school computer lab or single office building?**  
**පාසල් පරිගණක පර්යේෂණාගාරයක් හෝ තනි කාර්යාල ගොඩනැගිල්ලක් වැනි කුඩා භෞතික ප්‍රදේශයක් ආවරණය වන ජාල භූගෝලීය වර්ගීකරණය කුමක්ද?**

- (A) Wide Area Network (WAN) / පුළුල් ප්‍රදේශ ජාලය
- (B) Metropolitan Area Network (MAN) / නගර ප්‍රදේශ ජාලය
- (C) Local Area Network (LAN) / දේශීය ප්‍රදේශ ජාලය
- (D) Personal Area Network (PAN) / පෞද්ගලික ප්‍රදේශ ජාලය

<details>
<summary><b>View Answer & Flashcard Explanation / පිළිතුර සහ ෆ්ලෑෂ්කාඩ් පත් විස්තරය බලන්න</b></summary>

**Correct Answer:** **(C) Local Area Network (LAN)**

**Dual-Language Explanation / ද්විභාෂා විස්තරය:**
- **[English]:** A Local Area Network (LAN) connects computers and network devices within a limited geographical area such as a single room, building, or school campus. PAN covers a personal space (~10m), MAN spans a city, and WAN spans countries or continents.
- **[Sinhala]:** දේශීය ප්‍රදේශ ජාලයක් (LAN) යනු තනි කාමරයක්, ගොඩනැගිල්ලක් හෝ පාසල් පරිශ්‍රයක් වැනි සීමිත භූගෝලීය ප්‍රදේශයක් තුළ පරිගණක සහ ජාල උපාංග එකිනෙක සම්බන්ධ කරන ජාලයකි. PAN පෞද්ගලික ඉඩකඩක් (~10m) ද, MAN නගරයක් ද, WAN රටවල් හෝ මහද්වීප ද ආවරණය කරයි.
</details>

### Question 03
**What type of network topology connects all nodes directly to a central connecting device such as a Switch or Hub?**  
**සියලුම ජාල නෝඩ් (Nodes) ස්විචයක් (Switch) හෝ හබ් එකක් (Hub) වැනි මධ්‍යම සම්බන්ධක උපාංගයකට සෘජුවම සම්බන්ධ කරන ජාල ටොපොලොජිය (Network Topology) කුමක්ද?**

- (A) Bus Topology / බස් ටොපොලොජිය
- (B) Star Topology / ස්ටාර් (තාරකා) ටොපොලොජිය
- (C) Ring Topology / රින්ග් (මුදු) ටොපොලොජිය
- (D) Mesh Topology / මෙෂ් (දැලකාර) ටොපොලොජිය

<details>
<summary><b>View Answer & Flashcard Explanation / පිළිතුර සහ ෆ්ලෑෂ්කාඩ් පත් විස්තරය බලන්න</b></summary>

**Correct Answer:** **(B) Star Topology**

**Dual-Language Explanation / ද්විභාෂා විස්තරය:**
- **[English]:** In a Star Topology, all individual workstation nodes are independently connected to a central device (Hub or Switch). If one cable fails, only that workstation is disconnected, leaving the rest of the network operational.
- **[Sinhala]:** ස්ටාර් (තාරකා) ටොපොලොජියේදී, සියලුම සේවා මධ්‍යස්ථාන නෝඩ් මධ්‍යම උපාංගයකට (Hub හෝ Switch) ස්වාධීනව සම්බන්ධ වේ. එක් කේබලයක් අක්‍රිය වුවද, එම පරිගණකය පමණක් ජාලයෙන් වෙන් වන අතර ජාලයේ අන් කොටස් සාමාන්‍ය පරිදි ක්‍රියාත්මක වේ.
</details>

### Question 04
**Which transmission medium offers the highest data transfer speed and immunity to electromagnetic interference (EMI)?**  
**ඉහළම දත්ත සම්ප්‍රේෂණ වේගයක් සහ විද්‍යුත් චුම්බක බාධා කිරීම්වලට (EMI) පූර්ණ ප්‍රතිරෝධයක් දක්වන සම්ප්‍රේෂණ මාධ්‍යය කුමක්ද?**

- (A) Unshielded Twisted Pair (UTP) Cable / ආවරණය නොකළ ඇඹරි යුගල කේබලය
- (B) Coaxial Cable / කොඇක්සියල් කේබලය
- (C) Fiber Optic Cable / ෆයිබර් ඔප්ටික් (දෘශ්‍ය තන්තු) කේබලය
- (D) Shielded Twisted Pair (STP) Cable / ආවරණය කළ ඇඹරි යුගල කේබලය

<details>
<summary><b>View Answer & Flashcard Explanation / පිළිතුර සහ ෆ්ලෑෂ්කාඩ් පත් විස්තරය බලන්න</b></summary>

**Correct Answer:** **(C) Fiber Optic Cable**

**Dual-Language Explanation / ද්විභාෂා විස්තරය:**
- **[English]:** Fiber Optic cables transmit data as light pulses through thin glass or plastic strands. Because light is used instead of electrical signals, it provides ultra-high bandwidth and is completely immune to electromagnetic interference.
- **[Sinhala]:** ෆයිබර් ඔප්ටික් කේබල් මගින් දත්ත සම්ප්‍රේෂණය කරනු ලබන්නේ සිහින් වීදුරු හෝ ප්ලාස්ටික් තන්තු තුලින් ආලෝක ස්පන්ද (Light Pulses) ලෙසිනි. විදුලි සංඥා වෙනුවට ආලෝකය භාවිත කරන බැවින්, එය ඉහළම කලාප පළලක් (Bandwidth) ලබා දෙන අතර විද්‍යුත් චුම්බක බාධාවලට සම්පූර්ණයෙන්ම ප්‍රතිරෝධී වේ.
</details>

### Question 05
**Which network interconnecting device joins two different networks operating on different protocols and acts as a gateway entry point?**  
**විවිධ ප්‍රොටෝකෝල මත ක්‍රියාත්මක වන ජාල දෙකක් එකිනෙකට සම්බන්ධ කරමින් පිවිසුම් දොරටුවක් ලෙස ක්‍රියා කරන ජාල උපාංගය කුමක්ද?**

- (A) Network Interface Card (NIC) / ජාල අතුරුමුහුණත් කාඩ්පත
- (B) Gateway / ගේට්වේ (Gateway)
- (C) Repeater / රිපීටරය
- (D) Hub / හබ් එක

<details>
<summary><b>View Answer & Flashcard Explanation / පිළිතුර සහ ෆ්ලෑෂ්කාඩ් පත් විස්තරය බලන්න</b></summary>

**Correct Answer:** **(B) Gateway**

**Dual-Language Explanation / ද්විභාෂා විස්තරය:**
- **[English]:** A Gateway is a network node that connects two networks with different architecture and communication protocols (e.g. connecting a private LAN to the global Internet). A Router routes packets based on IP, while a Gateway translates protocol differences.
- **[Sinhala]:** ගේට්වේ (Gateway) එකක් යනු විවිධ ගෘහනිර්මාණ ශිල්පයන් සහ සන්නිවේදන ප්‍රොටෝකෝල සහිත ජාල දෙකක් එකිනෙකට සම්බන්ධ කරන ජාල නෝඩ් එකකි (උදා: පෞද්ගලික LAN ජාලයක් ගෝලීය අන්තර්ජාලයට සම්බන්ධ කිරීම).
</details>

### Question 06

- (C) To increase the physical speed of the CPU / CPU හි භෞතික වේගය වැඩි කිරීම
- (D) To clean dust from network router ports / ජාල රවුටර පෝට්වලින් දූවිලි ඉවත් කිරීම

- (B) The unique trail of data and online activity left behind by a user when performing digital actions on the Internet / පරිශීලකයෙකු අන්තර්ජාලය තුළ සිදු කරන ක්‍රියාකාරකම්වලදී ඉතිරි වන දත්ත සහ සබැඳි ක්‍රියාකාරකම් පිළිබඳ අද්විතීය සඩුව/සටහන

- (D) Physical footprints on a server room floor / සේවාදායක කාමරයේ පොළවේ ඇති භෞතික පා සටහන්
