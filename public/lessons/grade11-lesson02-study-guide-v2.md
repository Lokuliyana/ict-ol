# SECTION A: Complete Learning Guide & Short Notes (Comprehensive Theory)

### 2.1 Concept of a System & Information Systems (පද්ධතියක් සහ තොරතුරු පද්ධතියක් පිළිබඳ සංකල්පය)

#### 2.1.1 What is a System? (පද්ධතියක් යනු කුමක්ද?)
* **Definition:**
  * **[English Medium Text]:** "A system is a collection of components that interact to achieve a specific task."
  * **[Sinhala Medium Text]:** "පද්ධතියක් යනු යම් පොදු අරමුණක් සාක්ෂාත් කර ගැනීම සඳහා නිරන්තර අන්තර්-ක්‍රියාකාරීත්වයෙන් යුතු සංරචක සමූහයක එකතුවකි."

* **Textbook Illustration (Road Construction Machine / මාර්ග සංවර්ධන යන්ත්‍රය):**
  * When the components forming a road construction machine are not interconnected, the machine does not function properly and road construction is not possible.
  * When components are interconnected and work together towards a common goal, the machine functions as a system.

#### 2.1.2 Basic Elements of a System (පද්ධතියක මූලික සංරචක 3)

```
        ┌──────────────────┐       ┌──────────────────┐       ┌──────────────────┐
        │      Input       │ ────► │     Process      │ ─────►│      Output      │
        │     (ආදානය)      │       │     (සැකසීම)     │       │    (ප්‍රතිදානය)   │
        └──────────────────┘       └──────────────────┘       └──────────────────┘
```

* **[English Medium Text]:** "A system consists of three basic components: 1. Input, 2. Process, 3. Output. Input received by a system is converted to output by processing."
* **[Sinhala Medium Text]:** "ඕනෑම පද්ධතියක් මූලික සංරචක 3 කින් සමන්විත වේ: 1. ආදානය (Input), 2. සැකසීම / ක්‍රියාවලිය (Process), 3. ප්‍රතිදානය (Output). පද්ධතියකට ලැබෙන ආදාන, සැකසීම මගින් ප්‍රතිදාන බවට පත් කෙරේ."

* **Textbook Examples (පෙළපොත් උදාහරණ):**
  * **Example 1: School as a System (පාසල පද්ධතියක් ලෙස):**
    * **System (පද්ධතිය):** School (පාසල)
    * **Objective (අරමුණ):** To produce responsible, worthwhile, just citizens to society (රටට දෑයට වැඩදායක යහපත් පූර්ණ පූර්වැසියන් බිහිකිරීම).
    * **Input (ආදානය):** Children / Students (ළමුන් / සිසුන්).
    * **Process (සැකසීම):** The child is subjected to the teaching/learning process through interactions of teachers and other resources (ගුරුවරුන් හා සසුන් අන්‍යන්‍ය ක්‍රියාකාරීත්වයෙන් ඉගෙනුම් ඉගැන්වීම් ක්‍රියාවලිය).
    * **Output (ප්‍රතිදානය):** Providing good, educated citizens to the country (යහපත් පූර්වැසියන් ජාතියට දායාද කිරීම).
  * **Example 2: Weather Forecasting System (කාලගුණ අනාවැකි පද්ධතිය):**
    * **Input (ආදානය):** Atmospheric pressure, temperature, wind direction, humidity (වායුගෝල පීඩනය, උෂ්ණත්වය, සුළඟේ දිශාව, තෙතමනය).
    * **Process (සැකසීම):** Analyzing and computing meteorological data (දත්ත විශ්ලේෂණය හා ගණනය).
    * **Output (ප්‍රතිදානය):** Tomorrow's weather forecast report (හෙට දිනයේ කාලගුණ අනාවැකිය).

#### 2.1.3 Information Systems (තොරතුරු පද්ධති)
* **[English Medium Text]:** "A system which converts data into Information is known as an information system."
* **[Sinhala Medium Text]:** "දත්ත, තොරතුරු බවට පත් කරන පද්ධතියක් තොරතුරු පද්ධතියක් (Information System) ලෙස හැඳින්වේ."

```
        ┌──────────────────┐       ┌──────────────────┐       ┌──────────────────┐
        │       Data       │ ────► │     Process      │ ─────►│   Information    │
        │      (දත්ත)      │       │     (සැකසීම)     │       │    (තොරතුරු)    │
        └──────────────────┘       └──────────────────┘       └──────────────────┘
```

#### 2.1.4 Classification of Information Systems (තොරතුරු පද්ධති වර්ගීකරණය)
Information systems can be classified into two main categories:
1. **Manual Information Systems (අත්අයුරු / හස්තීය තොරතුරු පද්ධති):**
   * **[English Medium Text]:** "In this type of system all processes are done manually by human hands."
   * **[Sinhala Medium Text]:** "මිනිසා තම දෑතින්ම දත්ත සකස් කර ප්‍රතිදාන ලබා දෙන පද්ධති අත්අයුරු / හස්තීය තොරතුරු පද්ධති ලෙස හැඳින්වේ."
   * *Examples:* Manual student progress report system, paper library register, physical telephone directory book.
2. **Computer Based Information Systems - CBIS (පරිගණක පාදක තොරතුරු පද්ධති):**
   * **[English Medium Text]:** "A system which converts data into Information using a computer is known as a computer based information system."
   * **[Sinhala Medium Text]:** "පරිගණකයක් හා මෘදුකාංග ආධාරයෙන් දත්ත තොරතුරු බවට පත් කරන පද්ධති පරිගණක පාදක තොරතුරු පද්ධති ලෙස හැඳින්වේ."
   * *Examples:* Computerized library management system, computerized student database, automated banking system.

#### 2.1.5 Benefits of Computer Based Systems (පරිගණක පාදක පද්ධතිවල වාසි)
* **Example: Computer Based Library System (පරිගණක පාදක පුස්තකාල පද්ධතියක වාසි):**
  - Ability to maintain accurate records of those who have borrowed books.
  - Possibility to list those who have failed to return books on due dates quickly.
  - Establishes an online system for remote reservation and searching for books.
  - Ability to provide e-books to members.
  - Computer based library system can be networked with the main office to confirm return of books when issuing leaving certificates.

#### 2.1.6 Comparison: Manual Systems vs. Computer Based Information Systems (අත්අයුරු සහ පරිගණක පාදක තොරතුරු පද්ධති අතර ප්‍රධාන වෙනස්කම්)

| Feature (ලක්ෂණය) | Manual System (අත්අයුරු / හස්තීය පද්ධතිය) | Computer Based System (පරිගණක පාදක පද්ධතිය) |
| :--- | :--- | :--- |
| **Accuracy & Errors (නිරවද්‍යතාව හා දෝෂ)** | Since data is manually processed, there is more room for error.<br>(දත්ත හස්තීයව සකසන බැවින් දෝෂ ඇතිවීමට ඇති ඉඩකඩ වැඩිය.) | Errors are minimal with data processed by a computer program.<br>(සකසන ලද වැඩසටහනකට අනුව සිදුවන බැවින් දෝෂ ඇතිවීම අවම වේ.) |
| **Efficiency & Speed (කාර්යක්ෂමතාව හා වේගය)** | Processing of data is less efficient / takes more time.<br>(තොරතුරු සකසා ගැනීම සඳහා වැඩි කාලයක් ගතවේ / කාර්යක්ෂමතාව අඩුය.) | Data can be processed more efficiently and quickly.<br>(ඉතා කෙටි කාලයකින් කාර්යක්ෂමව තොරතුරු සකසා ගත හැක.) |
| **Storage & Physical Space (ගබඩා කිරීම හා භෞතික ඉඩ)** | Requires a large space for data storage (filing cabinets, cupboards required).<br>(දත්ත ගබඩා කිරීම සඳහා විශාල ඉඩ ප්‍රමාණයක් අවශ්‍ය වන අතර කබඩ් ආදිය අවශ්‍ය වේ.) | Large amounts of data can be stored in a small physical space using database software.<br>(ඉතා සුළු ඉඩ ප්‍රමාණයක විශාල දත්ත ප්‍රමාණයක් ගබඩා කර තබා ගත හැක.) |
| **Security & Backups (ආරක්ෂාව හා උපස්ථ)** | Data is open to a lot of threats (fire, damage, loss); not as safe.<br>(දත්ත නොයෙක් ව්‍යසනවලට භාජනය විය හැකි අතර ආරක්ෂාව සාපේක්ෂව අඩුය.) | Security can be ensured with backups and the use of passwords.<br>(උපස්ථ (Backups) යොදාගැනීමෙන් හා මුරපද භාවිතයෙන් වැඩි ආරක්ෂාවක් ලබාගත හැක.) |
| **Data Searching & Analysis (දත්ත සෙවීම හා විශ්ලේෂණය)** | Difficult to search, organize, and analyze data.<br>(දත්ත සොයා ගැනීම සහ විශ්ලේෂණය කිරීම අපහසු වේ.) | Fast searching, filtering, and efficient automated data analysis.<br>(දත්ත පහසුවෙන් සොයාගත හැකි අතර විශ්ලේෂණය කිරීම ඉතා පහසුය.) |
| **Manpower & Cost (මානව සම්පත හා පිරිවැය)** | More manpower is needed to manage paper files.<br>(ගොනු පවත්වාගෙන යාම සඳහා වැඩි මානව සම්පතක් අවශ්‍ය වේ.) | Less manpower needed, reducing long-term operational cost.<br>(අවශ්‍ය වන මානව සම්පත අඩු වන අතර මෙහෙයුම් පිරිවැය ද අඩු වේ.) |

### 2.2 System Development Life Cycle - SDLC (පද්ධති සංවර්ධන ජීවන චක්‍රය)

#### Core SDLC Definition (පද්ධති සංවර්ධන ජීවන චක්‍රයේ අර්ථ දැක්වීම)
* **[English Medium Text]:** "System Development Life Cycle (SDLC) is a structured, step-by-step framework used to design, develop, test, deploy, and maintain an information system effectively."
* **[Sinhala Medium Text]:** "තොරතුරු පද්ධතියක් සාර්ථකව සැලසුම් කිරීම, සංවර්ධනය කිරීම, පරීක්ෂා කිරීම, ස්ථාපනය කිරීම සහ නඩත්තු කිරීම සඳහා අනුගමනය කරනු ලබන ව්‍යුහගත පියවරෙන් පියවර ක්‍රියාවලිය පද්ධති සංවර්ධන ජීවන චක්‍රය (SDLC) ලෙස හැඳින්වේ."


#### Step 1: Identification of Requirements & Feasibility Study (අවශ්‍යතා හඳුනා ගැනීම සහ ශක්‍යතා අධ්‍යයනය)

1. **Requirement Gathering Techniques (තොරතුරු/අවශ්‍යතා රැස් කිරීමේ ක්‍රම 5):**
   * **Interviews (සම්මුඛ සාකච්ඡා):**
     * **[English Medium Text]:** "Meeting users directly to ask questions and collect detailed information about system requirements."
     * **[Sinhala Medium Text]:** "පරිශීලකයන් පෞද්ගලිකව හමු වී ප්‍රශ්න ඇසීම මගින් පද්ධති අවශ්‍යතා පිළිබඳ සවිස්තරාත්මක තොරතුරු රැස් කිරීම."
   * **Questionnaires (ප්‍රශ්නාවලිය):**
     * **[English Medium Text]:** "Distributing printed or digital questionnaires to a large group of users to gather data quickly."
     * **[Sinhala Medium Text]:** "විශාල පිරිසකගෙන් ඉක්මනින් තොරතුරු රැස් කිරීම සඳහා මුද්‍රිත හෝ ඩිජිටල් ප්‍රශ්නාවලි ලබා දීම."
   * **Observations (නිරීක්ෂණය):**
     * **[English Medium Text]:** "Watching the existing system processes and user activities directly in the actual working environment."
     * **[Sinhala Medium Text]:** "වත්මන් පද්ධතියේ ක්‍රියාකාරීත්වය සහ සේවකයන්ගේ කාර්යයන් සෘජුවම බලා නිරීක්ෂණය කිරීම."
   * **Document Review / Sample Collection (ලේඛන පරීක්ෂාව):**
     * **[English Medium Text]:** "Examining existing forms, reports, files, and manuals to understand current system procedures."
     * **[Sinhala Medium Text]:** "වත්මන් පද්ධතියේ භාවිත වන ආකෘති පත්‍ර, වාර්තා, ගොනු සහ උපදෙස් සංග්‍රහ පරීක්ෂා කිරීම."
   * **Prototyping (මූලාකෘතිකරණය):**
     * **[English Medium Text]:** "Creating a working model or prototype of the proposed system to demonstrate functionality and gather feedback."
     * **[Sinhala Medium Text]:** "යෝජිත පද්ධතියේ වැඩකරන මූලාකෘතියක් (Prototype) සාදා පරිශීලකයන්ට පෙන්වා අදහස් හා යෝජනා ලබා ගැනීම."

2. **Feasibility Study Types (ශක්‍යතා අධ්‍යයන වර්ග):**
   * **Technical Feasibility (තාක්ෂණික ශක්‍යතාව):**
     * **[English Medium Text]:** "Assessing whether required hardware, software, and technical skills are available to build the system."
     * **[Sinhala Medium Text]:** "පද්ධතිය සංවර්ධනය කිරීමට අවශ්‍ය දෘඩාංග, මෘදුකාංග සහ තාක්ෂණික දැනුම පවතීදැයි අධ්‍යයනය කිරීම."
   * **Operational Feasibility (ක්‍රියාකාරී ශක්‍යතාව):**
     * **[English Medium Text]:** "Evaluating whether the proposed system will solve the organization's problem and be accepted by users."
     * **[Sinhala Medium Text]:** "යෝජිත පද්ධතිය මගින් ආයතනයේ ගැටලුව විසඳෙන්නේද සහ පරිශීලකයන් එය පිළිගන්නේදැයි අධ්‍යයනය කිරීම."
   * **Economic Feasibility / Cost-Benefit Analysis (ආර්ථික / පිරිවැය-ප්‍රතිලාභ ශක්‍යතාව):**
     * **[English Medium Text]:** "Determining whether the financial benefits of the new system outweigh the development and maintenance costs."
     * **[Sinhala Medium Text]:** "නව පද්ධතියෙන් ලැබෙන මූල්‍යමය ප්‍රතිලාභ එහි සංවර්ධන හා නඩත්තු පිරිවැයට වඩා වැඩිදැයි අධ්‍යයනය කිරීම."

#### Step 2: System Analysis (පද්ධති විශ්ලේෂණය)

* **[English Medium Text]:** "System Analysis involves studying the existing system in detail, identifying its weaknesses and constraints, and defining functional and non-functional requirements for the new system."
* **[Sinhala Medium Text]:** "පද්ධති විශ්ලේෂණයේ දී වත්මන් පද්ධතිය සවිස්තරාත්මකව අධ්‍යයනය කර, එහි පවතින දුර්වලතා හා සීමාවන් හඳුනාගෙන, නව පද්ධතියට අදාළ කාර්යබද්ධ (Functional) සහ කාර්යබද්ධ නොවන (Non-functional) අවශ්‍යතා නිර්වචනය කරනු ලබයි."

* **System Analysis Modeling Tools:**
  * **Data Flow Diagram - DFD (දත්ත ගැලීම් සටහන්):** Visual representation of data movement, processes, data stores, and external entities.
  * **Entity Relationship Diagram - ERD (එන්ටිටි සබඳතා සටහන්):** Conceptual representation of database tables and relationships.

#### Step 3: System Design (පද්ධති සැලසුම් කිරීම)

* **[English Medium Text]:** "Designing the architecture of the new system, including User Interfaces (UI), Input Forms, Output Reports, Database Schema, and Logical Control Algorithms."
* **[Sinhala Medium Text]:** "නව පද්ධතියේ ගෘහ නිර්මාණ ශිල්පය, පරිශීලක අතුරුමුහුණත් (UI), ආදාන ආකෘති පත්‍ර, ප්‍රතිදාන වාර්තා, දත්ත සමුදා සැලසුම් සහ ලොජික් ඇල්ගොරිතම සැලසුම් කිරීම මෙහිදී සිදු කෙරේ."

#### Step 4: Software Development / Coding (පද්ධති සංවර්ධනය / කේතනය කිරීම)

* **[English Medium Text]:** "Translating system design specifications into functional software using a high-level programming language (such as Pascal, Python, C#, or Java)."
* **[Sinhala Medium Text]:** "පද්ධති සැලසුම් විවිතරයන් උසස් පෙළ ක්‍රමලේඛන භාෂාවක් (Pascal, Python, C#, Java වැනි) භාවිතයෙන් ක්‍රියාකාරී මෘදුකාංග කේත බවට පරිවර්තනය කිරීම."

#### Step 5: System Testing & Quality Assurance (පද්ධති පරීක්ෂාව)

1. **Levels of System Testing (පද්ධති පරීක්ෂාවේ මට්ටම්):**
   * **Unit Testing (ඒකක පරීක්ෂාව):**
     * Testing individual software components, modules, or functions independently.
     * තනි මෘදුකාංග ඒකක හෝ මොඩියුල වෙන් වෙන් වශයෙන් පරීක්ෂා කිරීම.
   * **Integration Testing (අනුකලන පරීක්ෂාව):**
     * Testing combined modules together to ensure seamless data flow between components.
     * මොඩියුල කිහිපයක් එකිනෙකට සම්බන්ධ කර දත්ත හුවමාරුව නිවැරදිදැයි පරීක්ෂා කිරීම.
   * **System Testing (පද්ධති පරීක්ෂාව):**
     * Testing the complete, fully integrated system end-to-end against requirements.
     * සම්පූර්ණ පද්ධතියම එකතු කර සමස්තයක් ලෙස පරීක්ෂා කිරීම.
   * **User Acceptance Testing - UAT (පිළිගැනීමේ පරීක්ෂාව):**
     * Testing conducted by actual end users / clients in the real operational environment before final acceptance.
     * පද්ධතිය භාර ගැනීමට පෙර සැබෑ පරිශීලකයන් / පාරිභෝගිකයන් විසින් පද්ධතිය පරීක්ෂා කිරීම.

2. **Test Data Types (පරීක්ෂණ දත්ත වර්ග):**
   * **Valid Data (වලංගු දත්ත):** Normal input data within expected ranges (e.g. Mark = 75).
   * **Invalid Data (අවලංගු දත්ත):** Out-of-bound or incorrect format data to check error handling (e.g. Mark = 150 or Mark = -20).
   * **Boundary Data (සීමාකාරී දත්ත):** Data values exactly on the minimum and maximum boundaries (e.g. Mark = 0, Mark = 100).

#### Step 6: System Implementation / Deployment Methods (පද්ධතිය ස්ථාපනය කිරීමේ ක්‍රම 4)

| :--- | :--- | :--- | :--- |
| **Direct Deployment<br>(සෘජු ස්ථාපනය)** | Old system is completely shut down and replaced immediately by the new system.<br>(පැරණි පද්ධතිය සම්පූර්ණයෙන්ම නවතා නව පද්ධතිය සෘජුවම ක්‍රියාත්මක කරයි.) | • Fastest implementation.<br>• Lowest initial operational cost.<br>(ඉතා ඉක්මන්, පිරිවැය අඩුය.) | • Highest risk.<br>• If new system fails, business operations stop.<br>(අවදානම ඉහළම වේ, දත්ත අහිමි විය හැක.) |
| **Parallel Deployment<br>(සමාන්තර ස්ථාපනය)** | Both old and new systems run simultaneously side-by-side for a specific period.<br>(පැරණි හා නව පද්ධති දෙකම යම් කාලයක් සමාන්තරව පවත්වාගෙන යයි.) | • Safest method.<br>• Backup system available if new system fails.<br>(අවදානම අවම වේ, පැරණි පද්ධතිය උපස්ථයක් ලෙස පවතී.) | • Highest operational cost.<br>• Double workload for staff.<br>(පිරිවැය අධිකය, සේවකයන්ට දෙගුණයක වැඩ ප්‍රමාණයක් ඇත.) |
| **Pilot Deployment<br>(නියමු ස්ථාපනය)** | New system is implemented in one branch or department first before full rollout.<br>(නව පද්ධතිය මුලින්ම එක් අංශයක හෝ එක් ශාඛාවක පමණක් ස්ථාපනය කර බලයි.) | • Low risk for whole organization.<br>• Issues isolated to one branch.<br>(සමස්ත ආයතනයටම ඇති අවදානම අඩුය.) | • Takes longer for full company-wide deployment.<br>(සමස්ත ආයතනයටම ස්ථාපනය කිරීමට වැඩි කාලයක් ගතවේ.) |
| **Phased Deployment<br>(අදියරමය ස්ථාපනය)** | New system modules are deployed in progressive phases/stages over time.<br>(නව පද්ධතියේ කොටස්/මොඩියුල අදියරෙන් අදියර ස්ථාපනය කරයි.) | • Users can adapt gradually.<br>• Problems isolated to specific module.<br>(පරිශීලකයන්ට ක්‍රමයෙන් හුරු විය හැක.) | • System integration issues between old/new modules.<br>(පැරණි හා නව කොටස් අතර සම්බන්ධතාව පවත්වාගැනීම සංකීර්ණ වේ.) |

#### Step 7: System Maintenance (පද්ධති නඩත්තුව)

* **Types of System Maintenance (පද්ධති නඩත්තු වර්ග 4):**
  1. **Corrective Maintenance (නිවැරදි කිරීමේ නඩත්තුව):**
     * Fixing software bugs, coding errors, or logic defects discovered during daily operations.
     * පද්ධතිය භාවිත කිරීමේදී හමුවන දෝෂ (Bugs) සහ වැරදි සකස් කිරීම.
  2. **Adaptive Maintenance (අනුකූලතා නඩත්තුව):**
     * Modifying software to work in new operating environments (e.g., OS upgrade, new hardware, legal/policy changes).
     * නව මෙහෙයුම් පද්ධති, දෘඩාංග හෝ නීතිමය වෙනස්කම්වලට අනුකූල වන සේ පද්ධතිය වෙනස් කිරීම.
  3. **Perfective Maintenance (පරිපූර්ණත්ව නඩත්තුව):**
     * Enhancing features, improving performance, or adding new user requirements to make the system better.
     * පද්ධතියේ කාර්යක්ෂමතාව වැඩි කිරීම සහ පරිශීලකයන්ගේ අලුත් අවශ්‍යතා එකතු කිරීම.
  4. **Preventive Maintenance (පූර්වාරක්ෂක නඩත්තුව):**
     * Routine checks, code refactoring, and security patches to prevent future software failures.
     * අනාගතයේදී සිදුවිය හැකි දෝෂ වැළැක්වීම සඳහා සිදුකරන පූර්වාරක්ෂක නඩත්තු කටයුතු.

### 2.3 System Development Life Cycle Models (පද්ධති සංවර්ධන ජීවන චක්‍ර ආකෘති)

#### 1. Waterfall Model (දියඇලි ආකෘතිය)
```
  [ Identification of Requirements ]
                 │
                 ▼
        [ Planning Solution ]
                 │
                 ▼
        [ Implementation / Coding ]
                 │
                 ▼
        [ Testing and Debugging ]
                 │
                 ▼
        [ Deployment of System ]
                 │
                 ▼
        [ System Maintenance ]
```
* **Key Characteristics:**
  * Sequential linear flow — each phase must be 100% completed before moving to the next.
  * Rigid and structured — suitable for simple projects with fixed, clear requirements.
  * **Limitation:** User sees the working software only at the end of the life cycle.

#### 2. Iterative Incremental Model (පුනර්කරණ-වර්ධී ආකෘතිය)
* **Key Characteristics:**
  * System is developed in repeating cycles (iterative) and small portions at a time (incremental).
  * Starts with a simple sub-set of requirements, then enhances versions through repeated feedback loops.
  * Allows developers to incorporate learning from previous cycles and user feedback early.

#### Question 04 (2022 O/L Paper I - Question 34)

  (2) Requirement identification -> Solution design -> Coding -> Testing -> Deployment
  (3) Solution design -> Coding -> Requirement identification -> Deployment -> Testing
  (4) Solution design -> Requirement identification -> Coding -> Deployment -> Testing"
* **Sinhala Medium Question:**
  "34. පද්ධති සංවර්ධන ජීවන චක්‍රයේ (System Development Life Cycle) තෝරාගත් ක්‍රියාකාරකම් පහත කුමක නිවැරදි අනුපිළිවෙලින් දැක්වේ ද?
  (1) කේතකරණය (coding) -> විසඳුම සැලසුම් කිරීම (solution design) -> අවශ්‍යතා හඳුනාගැනීම (requirement identification) -> පරීක්ෂා කිරීම (testing) -> පිහිටුවීම (deployment)

  (3) විසඳුම සැලසුම් කිරීම -> කේතකරණය -> අවශ්‍යතා හඳුනාගැනීම -> පිහිටුවීම -> පරීක්ෂා කිරීම
  (4) විසඳුම සැලසුම් කිරීම -> අවශ්‍යතා හඳුනාගැනීම -> කේතකරණය -> පිහිටුවීම -> පරීක්ෂා කිරීම"
