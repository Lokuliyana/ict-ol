# SECTION A: Complete Learning Guide & Short Notes (Comprehensive Theory)

### 4.1 Digital Graphics (අංකිත ග්‍රැෆික් / Digital Graphics)

#### 4.1.1 Concept & Fundamental Elements of Digital Graphics (මූලික සංකල්ප හා සංරචක)
* **Digital Graphic Definition (අංකිත ග්‍රැෆික් අර්ථ දැක්වීම):**
  * **[English Medium Text]:** "Images or graphics created using graphic software are known as digital graphics."
  * **[Sinhala Medium Text]:** "පරිගණක ග්‍රැෆික් මෘදුකාංග භාවිතයෙන් නිර්මාණය කරනු ලබන යම් කිසි තොරතුරක් ලබා දෙන චිත්‍ර හෝ රූප, අංකිත ග්‍රැෆික් (Digital graphic) ලෙස හැඳින්වේ."

* **4 Basic Elements of a Digital Graphic (අංකිත ග්‍රැෆික්වල මූලිකාංග 4):**
  1. **Pixel (පික්සලය):**
     * **[English Medium Text]:** "Pixel is the basic building element of a digital graphic. Digital graphics are made up of thousands of pixels. Pixel is composed of bits. Single colour pixel is made up of 8 bits while a colour pixel is made up of 24 (8×3) bits."
     * **[Sinhala Medium Text]:** "පික්සලයක් යනු අංකිත ග්‍රැෆික්වල මූලික තැනුම් ඒකකයයි. අංකිත ග්‍රැෆික් පික්සල දහස් ගණනකින් නිර්මාණය වී ඇත. පික්සලයක් බිටුවලින් (Bits) සමන්විත වේ. ඒක වර්ණ පික්සලයක් බිටු 8 ක් ද වර්ණවත් පික්සලයක් බිටු 24 ක් ද වේ."
  2. **Resolution (ග්‍රැෆික් විෆේඛනය):**
     * **[English Medium Text]:** "The unit to measure the physical dimension of a digital graphic is pixel and physical dimension is known as image resolution. A high resolution digital graphic has higher quality."
     * **[Sinhala Medium Text]:** "අංකිත ග්‍රැෆික්වල භෞතික පරිමාව (Physical dimension) මැනීමේ ඒකකය පික්සල වන අතර භෞතික පරිමාව ග්‍රැෆික් විෆේඛනය (Image resolution) ලෙස හැඳින්වේ. පික්සල ප්‍රමාණය වැඩි උසස් විෆේඛනයකින් (High resolution) යුතු අංකිත චිත්‍රයක් ඉහළ ගුණාත්මක බවකින් යුතු වේ."
  3. **Size (ප්‍රමාණය):**
     * **[English Medium Text]:** "The size of a graphic is determined by the number of pixels, the number of lines and the colour combinations used for the creation."
     * **[Sinhala Medium Text]:** "ග්‍රැෆික්වල ප්‍රමාණය තීරණය වන්නේ එය නිර්මාණයේ දී යොදා ගනු ලබන පික්සල ප්‍රමාණයට, රේඛා ප්‍රමාණයට හා යොදා ගනු ලබන වර්ණ සංකලනයට අනුව ය."
  4. **Colour Models (වර්ණ ආකෘති):**
     * **RGB Model (Red, Green, Blue):**
       * **[English Medium Text]:** "Primary colours (Red, Green, Blue) mixed to produce secondary and triplet colours. Used in computer displays and monitors. Primary colour variations range from 0 to 255. RGB Triplet is formed from 000,000,000 to 255,255,255 or in hexadecimal format like RGB(F5,66,24) or #F56624."
       * **[Sinhala Medium Text]:** "රතු, කොළ සහ නිල් (Red, Green and Blue) මූලික වර්ණ මිශ්‍ර වීමෙන් ද්විතියික හා තෘතීයික වර්ණ සෑදේ. පරිගණක තිර සඳහා භාවිත වේ. මූලික වර්ණක ප්‍රභේද 256 ක් (0-255) ඇත. තෘතීයික වර්ණයක් 'RGB Triplet' සෑදීම 000,000,000 සිට 255,255,255 දක්වා වේ."
     * **CMYK Model (Cyan, Magenta, Yellow, Black):**
       * **[English Medium Text]:** "Subtractive colour model used for physical printing on paper."
       * **[Sinhala Medium Text]:** "මුද්‍රණ කටයුතු සඳහා භාවිත වන වර්ණ ආකෘතියයි (ළා නිල්, දම්, කහ සහ කළු)."

#### 4.1.2 Graphic Compression: Lossy vs Lossless (ග්‍රැෆික් සංකෝචනය)

```
                       Graphic Compression (ග්‍රැෆික් සංකෝචනය)
                                  │
          +───────────────────────┴───────────────────────+
          │                                               │
Lossy Compression (හානි වන සංකෝචනය)            Lossless Compression (හානි නොවන සංකෝචනය)
          │                                               │
  - Reduces file size to minimum                  - Preserves original image quality
  - Reopened image loses quality                  - Reopened image opens in original form
  - Fast downloading from Internet                - Ideal for high-quality archiving
  - Examples: JPEG, TIFF, BMP                     - Examples: GIF, PNG, RAW
```

* **Lossy Compression (හානි වන සංකෝචනය):**
  * **[English Medium Text]:** "It is possible to compress graphics to a minimum size using Lossy file formats, but this compression reduces the quality of the original graphic. The reopened graphic does not show its original form. Yet, to make it faster for compression and for saving and downloading from the Internet, Lossy compression is useful. JPEG, TIFF, BMP are examples for Lossy file formats."
  * **[Sinhala Medium Text]:** "හානි වන සංකෝචන ගොනු ආකෘති (Lossy file formats) යොදා ගනිමින් ග්‍රැෆික් සංකෝචනය කිරීමෙන් ග්‍රැෆික්හි ධාරිතාව අවම මට්ටමක් දක්වා අඩු කර ගත හැකි නමුත් එහි තත්ත්වය විනාශ වේ. නැවත සෑදීමේ දී එහි ස්වාභාවික ස්වරූපය දක්නට නොලැබේ. නමුත් ග්‍රැෆික් සම්ප්‍රේෂණයේ දී සහ තැන්පත් කිරීමේ දී ඇති පහසුව මෙන්ම අන්තර්ජාලයෙන් බාගත කිරීම සඳහා අඩු ධාරිතාවක් සහිත ග්‍රැෆික් යොදා ගන්නා බැවින් හානි වන ග්‍රැෆික් සංකෝචනය වැදගත් වේ. උදාහරණ: JPEG, TIFF, BMP."

* **Lossless Compression (හානි නොවන සංකෝචනය):**
  * **[English Medium Text]:** "It is possible to compress a graphic preserving its original quality. In opening such a file, it is displayed in its original quality. This compression is identified as Lossless format. GIF, PNG, RAW are examples for Lossless file formats."
  * **[Sinhala Medium Text]:** "නිර්මාණය කරන ලද ග්‍රැෆික්වල ගුණාත්මක බව රැකෙන ආකාරයෙන් එය සංකෝචනය කළ හැක. නැවත සෑදීමේ දී එහි ස්වාභාවික ස්වරූපය දක්නට ලැබේ. එය හානි නොවන සංකෝචනය (Lossless) ලෙස හැඳින්වේ. උදාහරණ: GIF, PNG, RAW."

#### 4.1.3 Graphic Types: Raster vs Vector (රැස්ටර් සහ වෙක්ටර් ග්‍රැෆික්ස්)

| Comparison Criteria (සංසන්දනාත්මක පදනම) | Raster Graphics (රැස්ටර් ග්‍රැෆික්ස්) | Vector Graphics (වෙක්ටර් ග්‍රැෆික්ස්) |
| :--- | :--- | :--- |
| **Creation Method (නිර්මාණය වන ආකාරය)** | Array of pixels in different colours (මයික්‍රෝ පික්සල ආරාවකින් සමන්විත වේ) | Collection of straight/curved lines and shapes (සෘජු හෝ වක්‍ර රේඛා හා හැඩතල එකතුවකින් සෑදේ) |
| **File Records (ගොනු සටහන්)** | No records of mathematical lines (ගොනු සටහන් නොමැත) | Maintains record of start/end points, lines, curves, and fill colours (ආරම්භය, අවසානය, රේඛා ප්‍රමාණය, වර්ණ සටහන් පවතී) |
| **Enlargement / Quality (විශාල කිරීමේදී ගුණාත්මක බව)** | Quality is lost / pixelates when enlarged (පරිමාව වෙනස් කිරීමේදී ගුණාත්මක බව විනාශ වී යයි) | Quality is NOT lost when enlarged (පරිමාව වෙනස් කිරීමේදී ගුණාත්මක බව වෙනස් නොවේ) |
| **Suitability for Logos (ලෝගෝ සඳහා සුදුසු බව)** | Not suitable for logos/resizing (උසස් නිර්මාණ හා ලෝගෝ සඳහා නුසුදුසුය) | Highly suitable for logos/billboards (උසස් නිර්මාණ හා ලෝගෝ සඳහා ඉතා සුදුසුය) |
| **Memory Usage during Creation (මතක භාවිතය)** | Uses less computer memory during creation (පරිගණක මතකයේ ධාරිතාව අඩුවෙන් යොදා ගනියි) | Needs more computer memory during creation (පරිගණක මතකයේ ධාරිතාව වැඩියෙන් යොදා ගනියි) |
| **Software Examples (මෘදුකාංග උදාහරණ)** | *Adobe Photoshop, GIMP, Corel PHOTO-PAINT, MS Photo Editor, ProArtRage* | *Adobe Illustrator, CorelDRAW, Inkscape, Vectorian Giotto, Corel Paint Shop Pro, Adobe Fireworks* |

#### 4.1.4 Image Editing Software: GIMP (ග්‍රැෆික් සංස්කරණ මෘදුකාංග)
* **GIMP (GNU Image Manipulation Program):** Free, open-source raster graphics editor.
* **Key Tools & Icons in GIMP:**
  * **Rectangle Select / Ellipse Select:** Selecting rectangular or elliptical image regions.
  * **Free Select / Lasso Tool:** Manual freehand selection of irregular shapes.
  * **Fuzzy Select / Magic Wand:** Selecting continuous color areas based on color similarity.
  * **Text Tool:** Adding and formatting text overlays.
  * **Clone Tool (ක්ලෝන් fවුලම):**
    * **[English Medium Text]:** "Clone tool is used to duplicate pixels from one part of an image to another part to cover flaws or copy objects."
    * **[Sinhala Medium Text]:** "රූපයක එක් කොටසක ඇති පික්සල තවත් කොටසකට පිටපත් කරමින් පින්තූරයක පවතින අඩුපාඩු සඟවා ගැනීමට හෝ ප්‍රතිරූපණය කිරීමට ක්ලෝන් (Clone) fවුලම භාවිත කෙරේ."

### 4.2 Two-Dimensional (2D) Animation (දෙමාන සජීවීකරණය)

#### 4.2.1 Core Animation Concepts (මූලික සංකල්ප)
* **Animation Definition (සජීවීකරණය):**
  * **[English Medium Text]:** "Adding movement to static graphics to express ideas dynamically. Used in advertisements, cartoons, computer games, and web design."
  * **[Sinhala Medium Text]:** "ස්ථිතික ග්‍රැෆික්වලට සජීවී බව එක් කරමින් අදහස් ප්‍රකාශ කිරීමේ හැකියාව සජීවීකරණය මගින් සිදුවේ. වෙළෙඳ දැන්වීම්, කාටූන් චිත්‍රපට, පරිගණක ක්‍රීඩා සඳහා භාවිත වේ."

* **Key Terminology:**
  1. **Frame (රාමුව):** Individual sequential images in an animation timeline. Standard motion rate is **24 frames per second (24 fps)**.
  2. **Key Frame (මූලික රාමුව):**
     * **[English Medium Text]:** "Key frames are essential frames created directly by the user that define the starting and ending states/positions of an animation sequence."
     * **[Sinhala Medium Text]:** "සජීවීකරණයක ආරම්භක සහ අවසාන අවස්ථාවන්/පිහිටීම් තීරණය කරමින් පරිශීලකයා විසින් සෘජුවම නිර්මාණය කරනු ලබන ප්‍රධාන රාමු මූලික රාමු (Key frames) ලෙස හැඳින්වේ."
  3. **Blank Key Frame (වියුක්ත මූලික රාමුව):** Empty key frame provided to insert new drawings/content.
  4. **Tween Frames / Motion Tweening (ට්වීන් රාමු):**
     * **[English Medium Text]:** "Intermediate frames automatically generated by computer software between two user-defined key frames to create smooth movement."
     * **[Sinhala Medium Text]:** "මූලික රාමු දෙකක් අතර සුමට චලනයක් නිර්මාණය කිරීම සඳහා පරිගණක මෘදුකාංගය මගින් ස්වයංක්‍රීයව ජනනය කරනු ලබන අන්තරාල රාමු ට්වීන් රාමු (Tween frames) ලෙස හැඳින්වේ."

* **Vectorian Giotto Software:**
  * Free vector 2D animation software.
  * Native project file extension: **`.vgd`** (Vectorian Giotto Document).
  * Export file extension for web: **`.swf`** (Shockwave Flash / Export Flash Movie).

* **Sinhala Medium Question:**
  "5. (i) පුද්ගලයෙකු රූපයක් සුරැකීමට BMP අකෘතිය හෝ JPG අකෘතිය භාවිත කරන්නේදැයි තීරණය කිරීමට උත්සාහ කරයි.
  (a) අඩු ගබඩා ඉඩ ප්‍රමාණයක් ගනු ලබන්නේ කුමන අකෘතියද? හේතුව කුමක්ද?
  (b) වඩා හොඳ රූප ගුණාත්මක භාවයක් ඇත්තේ කුමන අකෘතියේද?
  (ii) රැස්ටර් (raster) සහ වෙක්ටර් (vector) චිත්‍රක ගොනු අතර මූලික වෙනස ලියා දක්වන්න.
  (iv) සජීවීකරණයක (animation) 'මූලික රාමු' (key frames) යන්නෙන් කුමක් අදහස් වේ ද?"
* **Official Answers:**
  - **(i) (a):** **JPG format.** Because JPG uses lossy compression algorithms to compress file size significantly compared to uncompressed BMP.
  - **(i) (b):** **BMP format.** Uncompressed image retaining original raw pixel quality.
  - **(ii):** Raster graphics are composed of an array of pixels (bitmap) and lose quality upon enlargement, whereas Vector graphics are composed of mathematical lines/curves and do not lose quality upon enlargement.
  - **(iv):** Key frames are essential user-created frames that define the starting and ending positions/states of an animation sequence.
